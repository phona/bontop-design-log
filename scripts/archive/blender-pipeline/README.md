> Blender is no longer an active project mainline. The default preview route is Web + GPT, while Web/CLI GLB export and comparison remain active. This directory preserves the final dirty/untracked workspace snapshot without committing, restoring, stashing, resetting, checking out, or cleaning it.

## Scope

The archive preserves the Blender-specific runtime, wrappers, render-bundle tooling, camera utilities, `verify-render-bundle`, and their related tests with their internal source layout:

```text
scripts/archive/blender-pipeline/
├── scripts/
│   ├── blender/                 # runtime, render config generator, checked-in config snapshot, Python tests
│   ├── render/
│   │   ├── bundle/              # bundle builder, utilities, and tests
│   │   ├── camera-preflight.ts
│   │   ├── camera-coverage-report.ts
│   │   └── preview-room-batch.ts
│   ├── verify/render/verify-render-bundle.ts
│   ├── run-blender.sh
│   └── test-run-blender.sh
├── tests/server/                # gen-render-config and render-bundle tests
├── metadata/                    # scrubbed copies of four selected metadata files
├── MANIFEST.json
└── README.md
```

Large or generated trees were intentionally not copied or moved: `assets/`, `hdri/`, `renders/`, and `tmp/` remain in place. Ignored binaries, Blender assets, textures, HDRIs, rendered PNGs, temporary bundles, `node_modules`, caches, and generated bytecode are not represented as archived payloads. Existing `scripts/blender/__pycache__/` and `.pytest_cache/` remain only at their ignored original locations and are not part of the cold archive.

## Recovery

No `archive:blender:*` npm aliases are provided. This archive is a source snapshot, **not a promise that rendering works directly from the archived paths**. The archived bundle/runtime source still contains historical repository-root paths such as `scripts/blender/...`; those paths are intentionally frozen for forensic fidelity rather than rewritten and falsely advertised as runnable.

To investigate a recovery, work in a separate disposable copy or branch and first reconstruct the historical paths from `MANIFEST.json`. Then restore external ignored resources from their existing locations, review environment-specific Blender configuration, and run wrapper/unit/bundle checks before attempting a render. Do not copy files over an active dirty workspace.

Historical invocation examples in the paused documents are evidence only; they are not current commands.
