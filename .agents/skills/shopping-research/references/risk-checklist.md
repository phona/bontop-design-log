# 风险清单

本文件在遇到阻塞、价格冲突、同款归并、批发字段或报告风险时读取。它用于让研究停止或披露，不用于扩大基础 Skill 的权限。

## 页面与认证状态

- `authentication_required`：停止该平台的当前分支，请用户在现有 Chrome 手工完成登录后再决定是否继续。
- `security_verification` / `site_blocked`：不拖动滑块、不输入验证码、不代输账号或短信、不刷新撞验证；记录阻塞 URL、时间和可见状态，必要时停止该平台。
- `layout_changed`：表示没有足够稳定的页面知识或字段缺口，不是成功，也不是无结果。
- `no_results`：只有页面明确表示无结果时使用；不要把空壳、登录页或加载不完整页面写成无结果。

一个平台阻塞时，其他平台只能作为独立覆盖，并在报告中披露平台缺口；不能用其他平台的结果替代被阻塞平台的事实。

## 只读交互边界

可以滚动、读取可见内容，或展开明确不涉及交易的参数/属性区域以读取已经存在的页面文本。任何购买、加入购物车、收藏、下单、支付、地址/账户修改、退款或确认按钮都不可点击或调用。不得自动登录、绕过验证码、提取凭据、保存 Cookie/token/HAR 或让浏览器退出。

同一浏览器不并发导航。使用命名 session：先用不带 pin 的命令记录 baseline target IDs，再用 pinned 命令创建/发现唯一 owned target，记录 targetId；只有在差集明确且当前 tab 集合仍可证明为 baseline 加 owned 时才导航和清理。客户端 session 清理无法证明安全时不执行。

## 价格、SKU 和单位风险

- 展示价可能是起价、区间价、券后价或未选 SKU 价格；原始文案、`kind` 和金额分列保存。
- 未明确选择 SKU 时，`skuResolved=false`；不得声称价格对应用户想要的颜色、尺寸、容量或组合。
- 1688 的 MOQ、销售单位和每档阶梯价分别保留；不能把批发起订价直接同单件零售价比较。
- 运费、地区、税费、配送时效和促销有效期缺失时列为未知，不使用假设金额做精确排名。
- JD 评论数不是销量；当前没有 reviews，口碑、耐用和售后体验均未验证。

## 候选、店铺和同款风险

广告/推广只说明展示属性，不是质量或推荐证据。不同平台商品 ID 不同并不证明是不同产品；只有型号、规格、包装、图片、单位和店铺证据一致时才标“疑似同款”，证据不足就保持分开。店铺/公司名相似也不证明同一主体。

淘汰必须能回溯到硬约束、价格口径、状态、重复或证据缺口。不能因缺少评论而编造负面评价，也不能把销量、成交、页面排序推断成质量或售后结论。

## 报告前风险闸门

交付前逐项问：

1. 推荐是否满足所有硬约束，还是只满足偏好？
2. 比较是否在同规格、同单位、同地区和同费用口径下成立？
3. 是否把广告、默认 SKU、起价、券价、MOQ 或阶梯价误当成可直接支付价格？
4. 是否把推断写成事实，或把未知写成好/坏？
5. 所有关键结论是否有 URL、`observedAt` 和原始 `status`？
6. 是否披露了未安装基础 Skill、平台阻塞、layout 缺口和未验证的 reviews/体验信息？

任一关键问题未解决，就降低推荐强度、标注风险或停止，而不是补猜测。
