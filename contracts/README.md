# contracts / 合同归档

所有与项目相关的合同、协议、报价单归档于此。

## 目录说明

| 目录 | 用途 |
|------|------|
| `design_service/` | 设计服务合同 |
| `construction/` | 施工合同 |
| `material/` | 材料采购合同/订单 |

## 合同审查清单

- [ ] 甲乙双方信息完整
- [ ] 工程范围清晰，无模糊合并项
- [ ] 付款节点与验收条件绑定
- [ ] 增项上限约定（建议 ≤5%）
- [ ] 材料品牌型号锁定
- [ ] 工期与延期赔偿条款
- [ ] 质保期限与范围
- [ ] 争议解决方式
- [ ] 双方签字盖章
