# phase-1 / 一期基本入住

状态：`planning`。

- `control.yaml`：唯一维护源；
- `budget.md`：自动生成预算视图；
- `schedule.md`：自动生成施工视图；
- `checklist.md`：自动生成逐项审计清单。

现场推进先看项目总入口 [`../checklist.md`](../checklist.md)，再按当前工作包打开本阶段 [`checklist.md`](checklist.md)。数据、预算和验收要求变化后先运行 `npm run schedule:render`；`npm run verify:schedule` 会只读报告过期视图。

临时入住与一期竣工是两道不同的门：本阶段的 [`PKG-142 临时入住放行`](checklist.md#pkg-142) 排在基础硬装、固定机电与中央空调验收后，不要求家具、完整窗帘或全部家电先入场；它仍要求最低生活功能、安全、室内环境和未完工程安排逐项通过。通过 PKG-142 只代表可以按已签认清单暂住；一期仍须完成窗帘、家具/家电范围和 [`PKG-170 竣工联合验收`](checklist.md#pkg-170) 才算最终收尾。

家电型号和公开参考价登记在 `control.yaml` 的 `appliance_quote_register`；其中燃气热水器已确认类别，主选候选与预算备选仍须在交房后完成现场安装条件、气源、排烟、接口和含辅材报价核对。
