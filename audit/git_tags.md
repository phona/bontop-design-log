# Git 里程碑标签

| 标签 | 含义 | 触发条件 | 日期 |
|------|------|----------|------|
| `v0.0-init` | 项目初始化 | 目录结构与核心文件创建 | 2026-07-03 |
| `v0.1-concept` | 概念方案锁定 | AI生成3版，业主选定1版 | |
| `v0.3-survey` | 量房数据录入 | 现场量房完成 | |
| `v0.5-layout` | 布局定稿 | 漫游验证，家人确认 | |
| `v0.7-design` | 施工图完成 | 设计师深化图纸交付 | |
| `v0.9-contract` | 合同签订 | 施工方选定，合同归档 | |
| `v1.0-construction` | 开工 | 首笔付款完成 | |
| `v1.x-changes` | 施工变更 | 每次变更后 | |
| `v2.0-completion` | 竣工 | 验收完成，尾款结清 | |

## 打标签命令

```bash
# 量房完成后
git add .
git commit -m "[量房] 完成现场量房并录入精确户型数据"
git tag v0.3-survey

# 布局定稿后
git tag v0.5-layout

# 以此类推
```
