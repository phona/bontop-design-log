# 视觉类改动 Playbook（3D / 渲染反馈环）

> **适用范围**：任何「业主看图说话 → 改模型 → 再看」的迭代（吊顶、材质、灯光、家具摆位……）。
> **不要求每场会话必读**——视觉迭代开工时来取；最高频的两个门禁已做成命令和硬规则，见 §1/§5。
> **来历**：DEC-2026-10-08-R01~R05（餐厅吊顶一个 0.5m 的角，六轮返工）——本 playbook 是那份痛苦的方法论沉淀，案例即反例教材。

## 0. 一句话原则

**视觉改动的成本不在几何，在环。** 环通着（你看的就是我改的），错三轮都能收敛；环断了，一轮能错六次。所有规则都服务于：让每一次错误猜测的代价 = 一次刷新。

## 1. 状态门（动手分析前，硬规则）

客户端渲染的必须是当前 config。**动手前和交付前各跑一次**：

```bash
npm run gate:visual     # CLEAR / STALE + 修复命令；退出码 0/1/2
```

- STALE 的处理只有一件事：**重启 dev server + 浏览器硬刷新**，不要怀疑自己的几何。
- 环境已知坑（本 playbook 的存在理由）：`ProjectRenderFactsLoader` 的 chokidar watch 不可靠，且**失败是静默的**——schema 拒绝新字段时 load() 失败、旧 facts 原样保留。历史上它让业主对着 5 小时前的渲染给了六轮反馈。
- 任何「改完了你看」的报告，必须先附本门的 CLEAR 输出。

## 2. 词汇门（第一轮回复内完成，硬规则）

业主说「弧 / 圆角 / 弧面」时，**先封闭确认再动手**：

- **平面圆弧**（角本身圆过来，俯视看得见）≠ **交线弧**（立面与平顶交接那道 cove，仰视看得见）。
- 本项目精确词汇，与业主对话时主动映射：**阴角/凹弧**（加料填口）、**阳角/圆角**（切料）、**cove**（交线弧）、**边吊**（边吊顶）。

## 3. 平面图门（争角部时，先画再争）

先画俯视（ASCII 即可），每个角标四件事：哪几个分区在这交汇、料在哪个象限、开口在哪个象限。然后十秒定性：

| 开口 | 料 | 定性 | 治法 |
|---|---|---|---|
| 90° | 270° | **阴角** | 凹弧（加料，SW 拐肘同款） |
| 270° | 90° | **阳角** | 圆角（切料） |

案例：餐厅东南角 (10.80,3.00) 是阴角（门头盒占西北、门厅占东北/东南，开口西南）——阳角圆一切就出「口子」且弧到不了另一边；凹弧才能相切过渡到门厅西缘。**这个结论第一轮就能画出来**，实际到第六轮才画。

## 4. 业主的丑话 = 规格，不是否决

| 业主的话 | 几何含义 |
|---|---|
| 狗啃 | 收口齐烂 / 圆弧末端没有干净收头 |
| 缺了个口子 | 有缺口（圆角退缩区没被邻区覆盖） |
| 不应该是垂直的平面吗 | 不要交线弧，立面保持平面 |
| 圆弧过渡到另一边 | 弧要连续接到相邻面，不能断 |
| 一圈圆 | 所有外露角统一圆角语言 |

第一轮就解码成 spec；解码不了的再问，不要辩论审美。

## 5. 分级动手 + 两次规则

- config 能表达（声明式）就先 config；**同一个点两次 config 修不好 → 停下做架构评估**——那是模型表达力不足的信号（本例：cove 不过分区、角归两区共有），不是参数问题。本例信号第二轮就在，拖到第五轮。
- 留痕分级：**机制级**改动（builder / 算量 / schema）走 DEC + 五件套 + 测试全套；**纯视觉微调**（半径、拆/加一处声明）只记一条 DEC + 一个 probe 数，不开五件套。

## 6. 交付格式（每次变更报告）

数字 delta + 指定验收机位，缺一不可。范例：

> 轮廓 bbox x[7.70,10.80] z[2.40,3.15]；切点 (10.65,3.00) 与 (10.80,3.15)；不越 x=10.80；净面积 +0.0048㎡。**从餐桌朝东南角看**：平面圆弧相切转到门厅西缘，垂面全是光面。

没有数字和机位的「改好了」= 没交付——业主无法用审美印象验证，只能用眼睛在指定位置对事实。

## 7. 选项按视觉结果描述

给业主的选项写「长什么样 + 代价」，不写实现口径：

- ✅「转角相切过渡到另一面（要改 builder，半天）」
- ✅「转角圆但留一道影线级的缝（配置级，十分钟）」
- ❌「给门厅加 cove_fillets west」——业主无法想象，选了也不是他想要的。

## 8. 决策日志是证据，不是圣经

终裁可能是工具卡住时的退让（本例原话：「回正交是因为实在改不动了」）。**重开条件：该决策的验收证据是在反馈环坏了的时候做的。** 重开时显式记一条新 DEC 废止旧条款，不静默翻案。
