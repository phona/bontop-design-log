## 2. 质询一：厨房东墙（烟机/高柜后）为什么贴砖

**定位依据**：图3 工具提示为 `range_hood`、东向轴、高柜位 = `fridge@(10.45,2.05)`；即 `w_ent_west` 厨房侧整段 2.40m。

**结构事实**：0.90m 带正好是地柜台面（完成面 0.89m）以下，被东墙 L 型地柜 z[0.30,1.70] 与冰箱高柜 z[1.70,2.40] 全覆盖——整段 2.40m 都是遮蔽面，这也正是它 `zone: covered` 的原因。

**当初为什么贴（三条）**：
1. 2026-10-07 业主指示：遮蔽面仍贴砖、走杂砖（用杂砖控主材，同时保持「面积不减遮蔽」的人工辅材口径，防与瓦工双计）。
2. 高柜/冰箱柜体挂装螺丝需要砖体基层；抹灰层直接打孔易掉渣成渣孔，这是行业里「高柜后贴杂砖」的常规理由。
3. 遮蔽面杂砖单价无记录，主材口径暂计 0，成本影响显式挂账。

**你的质疑成立的部分**：冰箱/高柜背后这段若接受「未来不动柜」，边际价值低。可取消的量级：厨房 covered 3.42㎡，对应人工约 300 元（厨房大砖混贴 90 元/㎡锚点）+ 辅材约 50 元 + 免杂砖采购；但要注意费率表「厨房大砖搭杂砖按大砖单价」的报价惯例——取消范围必须让泥工按实际范围重报，不是自动减免。

**你的质疑不成立、需要纠正认知的部分**：烟机灶台后、台面以上到烟机底（约 1.5–1.6m）这段约 0.75m×0.6m ≈ 0.5㎡ 的油溅区**目前没贴砖**——吊柜未覆盖、无挡水条，是裸墙。真正该补的是这一段，而不是纠结台面下的杂砖带。

**选项**：
- **A 维持**：杂砖照贴，零改动。
- **B 收缩（建议）**：冰箱高柜后段（约 0.6–0.7m）改水泥砂浆找平不贴；灶台段保留并向上补到烟机底。既回应你的质疑，又补上真正的缺口。
- **C 全不贴**：与 2026-10-07 业主指示相反，不推荐（失去打孔基层、未来换柜返潮无保护）。

## 3. 质询二：厨房-阳台门/地漏区为什么没贴砖

**定位依据**：图2 为厨房内西望生活阳台门，地漏 `drain_balc_floor@(6.5,1.5)`、洗衣机烘干叠放贴 `w_balc_west@(5.95,1.5)`、墙排 `drain_balc_washer@(5.8,1.5)`。

**结构事实**：厨房侧已贴三段（含门洞厨房侧两旁的 `w_balc_east` 1.20m 与 `w_kit_west` 残段 0.20m）。**未贴的是生活阳台自身**：
- `w_balc_west` 1.20m（洗衣机/烘干机背后的墙，给水/墙排/插座全在这面墙）；
- `w_balc_south` 阳台侧 1.50m（与客卫花洒共墙，客卫侧已贴 1.80m，阳台侧裸墙）；
- 门洞两侧门垛的阳台侧脸。

即：全宅唯一有洗衣机+地漏的湿区，一面墙砖都没有。

**定性：成立**。按本案自己的口径（客卫非淋浴区都贴了 0.30m）和费率表里现成的「阳台墙砖 80 元/㎡」锚点，阳台湿区至少 0.30m。

**选项**（价格按锚点推断，回店报价为准）：
- **A 最小**：门垛两侧 + 洗衣机墙露明段，约 0.16㎡，量级合计约 20 元。
- **B 顺手（建议）**：`w_balc_west` + `w_balc_south` 阳台侧均 0.30m ≈ +2.70m×0.30m = 0.81㎡；人工约 65 元 + 主材约 57 元 + 辅材约 12 元。
- **C 与厨房齐 0.90m**：洗衣机上方甩水全部接住，≈ 2.43㎡；人工约 195 元 + 主材约 170 元。

**影响**：可贴实体墙总长 14.86m → 17.56m，控制文件 COST-060-08 与 L2 断言的 DEC 数字需同步。

## 4. 质询三：落地窗一圈防水台没贴砖

**结构事实**：这不是漏了一两处，是体系不表达——
- `bay_sill` 10 段（主卧西/南、书房南、客房南、西北次卧西/北、走廊西、主卫西北、厨房北……）只声明了几何（sill 2.07/2.12m、depth 1.1m），没有任何面层；
- `wall_region` 只覆盖竖直墙面（0→0.30/0.90/1.80m），表达不了水平窗台/防水台；
- `floor_region` 只管地面。

**但成本系统早有锚点**：「窗边台贴小砖条 20 元/米」「飘窗台面贴砖 100 元/米」（COST-060-05 extras）——这项会发生、会花钱，只是没进贴砖方案。

**范围确认**：真·落地窗只有客厅南幕墙 `w_liv_south`（z=9.80，x 7.20→13.40 = 6.20m，齐地玻璃）；厨房北幕墙是 2.12m 上光带飘窗（非落地）。请确认「一圈」是否只指客厅落地幕墙根部，还是含全部飘窗台面。

**施工口径建议（推断）**：
- 客厅落地幕墙根部防水台：贴砖或石材窗台板出檐收口，遮住水泥沿、防雨水顺框下渗；按飘窗台面贴砖 100 元/米量级 ≈ 620 元（6.20m）。
- 飘窗台面是坐台，建议窗台石而非墙砖（耐候、可留滴水）——与墙面砖不同材，是否纳入由你定。

**落地方式建议**：不为渲染扩 schema，直接进瓦工交底清单 + `config/budget-pitfalls.yaml` 验收条目（窗台/防水台面砖空鼓、留缝、出檐），费用挂 COST-060-05 extras。

## 5. 顺带核对发现（本次质询暴露的另外三个点）

2. **`wall_region` 没有脸语义**：`paint_region` 有 `room` 字段声明贴哪侧脸，`wall_region` 没有；共墙（`w_balc_south`/`w_balc_east`）新增声明时必须明确贴哪侧脸，否则渲染和预算的脸会错。建议本次顺手补上。
