# 玄关双面半高柜结构深化输入单

**版本**：EC-700-SD-01  
**状态**：业主已冻结设计基线；用于柜商出深化图，不是生产下料单或施工放线图。  
**范围**：仅半高柜和相邻冰箱接口。冰箱、餐桌、吊顶、门洞、玻璃门和柜体主体位置保持现状。

## 1. 冻结尺寸与平面分段

| 台面完成面 | 最终完成地面以上920mm |

台面外廓从 z=2.980m 延至5.020m，因此低端裸台面约720×393mm（约0.283㎡）；按柜体主体的700mm分段算，名义面积为0.245㎡。图纸须分开标注“低区主体长度700mm”和“台面含北端外挑后的裸露长度约720mm”。

柜体主体边界：x[11.325,11.675]、z[3.000,5.000]m。台面边界：x[11.3035,11.6965]、z[2.980,5.020]m。坐标为当前模型/试位，现场复尺后用于放线。

### 上部立面

- 北端700mm上方保持开放，仅留920mm平整暖白台面。
- 南段保留1420mm高位界面：入户东面浅橡木背板、18mm转折端板和南端板、暖白40mm帽板。
- 餐厅侧上部按单一开放龛位处理；920mm台面为龛位底，帽板底为顶，名义进深350mm。本单不增加中间展示层板、格栅或灯带。
- 转折端板入户可见面跟浅橡木；所有露边封边。帽板下方加隐藏承托，避免形成无支撑悬挑。

## 2. 双面正面与内部结构

### 入户东侧

- 踢脚以上至Y=700mm：18mm浅橡木连续固定面板，不设下部平开门或开放格。
- Y=700–860mm：保留Round7已确认的两片抽面、一道中缝；按1964mm净长，两片可视宽约981mm/片，中缝预留约2mm；柜商按实际侧缝、导轨和安装间隙均匀扣减面板宽度。不得未经业主确认改成三片可见抽面。
- Y=860–880mm：柜体顶板下设连续18mm承托横档，正面同浅橡木齐平收口；余下2mm计入台面/封边安装公差，正面不留黑缝或额外装饰线。
- 抽面18mm浅橡木，顺纹排版；上口做简单指扣/暗拉手，不增外露长拉手。
- 抽屉箱体预演起点：单只约948mm沿柜长、约140mm高、约280–296mm深。18mm箱侧板、建议12mm箱底；导轨型号、侧隙和最终箱宽以实物安装模板为准。
- 抽屉下设连续18mm隔板/承托板，暂按Y=682–700mm。柜内分隔只做到抽屉带，不向下延伸阻断北段储物。

### 餐厅西侧

餐厅正面按主体两端18mm侧板之间的1964mm内长闭合：

| 从北向南 | 名义尺寸 | 功能 |
|---|---:|---|
| 北段固定面 | 970mm | 低频储物，不设日常开门 |
| 中立梃 | 24mm | 固定段与门扇间结构/门缝 |
| 南段门扇段 | 860mm | 普通平开门候选段；铰链在南端，向西开。门扇净宽、门缝、铰链占位和实际净开口由柜商回图 |
| 南端填充 | 110mm | 固定收口 |
| 两端侧板 | 18mm + 18mm | 主体端板 |

尺寸链：970+24+860+110=1964mm；加两端18mm，主体2000mm。860mm是门扇分段候选，不是已确认净开口。固定北段后方必须与南段内腔连通；不得加贯穿全高的南北隔板。北段只放低频物品/手提收纳盒，不作为日常取餐具区。

下柜内腔名义深度314mm（350mm主体减两面18mm板）。低柜储物带暂按Y=98–682mm，设置一层18mm可调层板，默认上表面约Y=399mm，形成约283mm上下两层。层板按南北三段，每段约655×314×18mm；分段便于搬运，但“可经南门通过”仍须按柜商实际净开口和转向路径验证。柜商须画出北段层板、最大常用收纳盒由南门装入、移至北段、再取出的完整路径，并现场用等尺寸样板演示。层板沿前后两条纵向承托条支承，不用全深隔板、拉篮或旋转五金。

### 北段容量与可达性

- 名义内腔：长1964×深314×净高584mm；扣除一层18mm层板后，理论开放容积约`1.964×0.314×0.566=0.349m³`，即约349L。该数值是几何上限，不扣五金、支撑条、收纳盒壁厚和手部操作余量，不等于可装满的有效容量。
- 北侧970mm固定立面后方的长度占内腔约49.4%；按相同截面折算约172L理论空间。它没有独立正面开口，必须由南侧门扇段进入，并沿连续内腔向北移动物品。
- 南侧860mm门扇段对应约44%的内腔长度；门扇打开后是直接取放区，但实际净开口小于或等于门扇段，尚未由铰链与门缝图确认。门外冰箱不与内腔相交，但其近邻关系使“从正面直接取北段”不成立。
- **使用判断**：若柜商能证明最大常用箱/篮和层板都能经实际净开口进出，并能从南门顺畅推拉到北端，北段约172L低频储物值得保留；建议放替换纸品、备用餐具或整篮物品，不放每天拿取的杯盘。若样板路径失败，北段容量不得计入可用收纳，应按空腔/封闭死角处理并重新核算，不以“有内部空间”代替可用性证明。

## 3. 板材、收口、承托与固定

这些是柜商深化口径，不含品牌或采购SKU。

- 柜体侧板、顶/底板、固定北面、柜门和背板：建议18mm柜体级板材；报价/深化图列出板芯、耐潮和环保等级。
- 可调层板：18mm；入户橡木可视板18mm；餐厅门板暖白18mm。
- 外露木纹边建议2mm同色封边并小倒角；常规内藏边0.8–1mm；不露芯、不加装饰条。
- 台面与帽板的预演厚度均40mm。供应商须标明芯层、面层和封边剖面；不得以空腔饰条凑40mm。台面支撑按393mm总深、前后各约21.5mm外挑校核。
- 台面下沿柜长方向设置连续承托，抽屉分隔/侧板处加横向承托；1420mm帽板设置隐藏的连续前后承托边和两端返回板。承托不能变成阻断北段收纳的全深隔板。
- 采用可调脚找平及隐藏防倾倒固定；固定到楼板/实墙前，现场确认基层、暗管和可钻位置。不得只固定在地砖、石膏板或玻璃幕墙上。
- 踢脚保留约80mm高内缩体量；柜商现场核对踢脚、门套、门扇、抽屉和脚尖空间。

## 4. 冰箱与柜门/抽屉几何核验

当前模型中的冰箱试位为x[10.640,11.240]、z[3.0635,3.8965]m，门面朝西。到台面西边缘的间距约63.5mm，到柜体主体西边缘约85mm。这只是几何间距，不是散热或安装合格结论。

- 北固定面与冰箱z投影重叠，但北段不设餐厅侧门。
- 南门候选范围z[4.012,4.872]m；冰箱最南至z=3.8965m，相隔约115.5mm。按向西开到90°的临时门扇包络x[10.456,11.316]m、z[4.012,4.872]m，与冰箱AABB无三维相交。若五金允许110°，门扇会越过柜体南端约166mm，仍需核南侧通行。
- 入户门d_ent的保守扫掠z上界约2.92m；北抽屉前缘约z=3.018m，模型余量约98mm。按300mm全拉行程候选，东向抽屉最大x约11.993m；到东侧边界x=13.40m余约1.407m。门套、门吸、执手、拉手和真实导轨还未入包络。
- 冰箱向西0.60m的旧模型包络留有通道，但该值不是实际厂家门扇/抽屉动作数据。
- 当前未取得HR-518WUFIPZ可追溯的型号安装图；不得把63.5/85mm间距或模型门扇包络写成厂家净空已合格。
- sock_kitchen_fridge (10.80,2.05,h=0.30m) 和strong-ded-fridge仍属旧厨房端点，不是新位置可用插座。新位置专用电源需电工另定，禁止藏在冰箱后、柜后或65mm缝中。

柜商回图须按实机和现场门套叠加四种状态：冰箱门开、冰箱抽屉全拉、南柜门全开、入户浅抽屉全拉/同开；同时标出检修、更换路径和人体站位。不以静态AABB代替实际活动包络。
