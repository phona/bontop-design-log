# 夜景东南静态光源复盘

**迭代 ID：** `night-global-source-mismatch-20261015`

## 触发与根因

业主截图显示红框区域仍有东南方向投影。截图本身没有显示日照开关状态。代码中的静态主方向光固定在 `[12,20,8]`、强度 `0.9`、开启投影；按项目坐标约定，这正是东南上方。关闭日照模拟会恢复静态日间预设。另一个入口“夜景手动”之前只切换室内灯，没有关闭全局光。

在 5173 的当前工作区实例中，21:00 / 太阳高度角 `-38.4°` / `sunlightEnabled=false` 可稳定复现：主方向光 `visible=true`、强度 `0.9`，ambient `0.55`、fill `0.3`、环境贴图存在。根因与用户截图高度吻合；截图上的具体开关状态没有直接显示。

## 修复

- 日照模拟关闭时，时间滑块仍能改变当前昼夜状态；太阳高度角小于等于零即关闭太阳、环境光、辅助补光和 IBL，室内灯按该状态自动开启。
- “夜景手动”改为明确的“仅室内灯”模式，独立关闭所有全局光，即使太阳状态是白天也生效；UI 标签同步说明该行为。
- 关闭日照模拟时，App 将实际保留的昼夜状态继续传给室内灯系统。白天仍使用原静态预设。
- 室内吊灯是当前唯一启用阴影投射的灯具。它造成的局部室内阴影会保留；本轮没有关掉室内灯的正常投影能力。
