# R25 客餐厅冷凝水汇流与路由候选

**状态：协调候选，非施工放线。** 该轮基于仓库 `514c715`，把客厅 71T2 与餐厅 42T2 两条冷凝水管建模为独立支管、明确Y型汇流节点和一根共用主管。节点、管径、保温、设备出口高度及接水做法都保留为可回写的假设。当前几何见[平面图](plan.svg)与[剖面图](section.svg)，配置在 `config/mep-hvac-coordination.yaml`、`config/hvac.yaml`。

## 推荐拓扑与当前低设备依赖候选

两台内机分别以 φ25 支管进入节点 `(6.80, 3.70, 2.435)`，节点暂按45°Y型接头建模，之后由一根 DN32 共用主管垂直下引至约 `y=0.101m`，以0.10m长、1%坡度接到现有候选排水点 `(6.70, 3.70, 0.10)`。排水点坐标保持不变。DN32是按两台同时排水的初步选径，厂家/安装方尚未提供流量与共管许可；6mm保温和0.06m局部接头包络也都未确认。

当前配置保留“少依赖内置泵”的自然重力路线作为交底基准候选。两条支管水平段按每段长度和标高差实算，最低分别为1.00%和约4.93%，均超过1%设计最低值；末端没有反坡。出口坐标及标高2.52m仍是假设，不能据此认定 P-SS 机型有可用自然重力口或厂家允许泵旁通。自然重力方案不增加外置泵，但客厅一段外包络会低于2.50m完成面约65–74mm，餐厅分支在所经分区也有明确低于完成面的提示；客厅约3.92m与餐厅约0.44m的段落尚需设计吊架，不能用未批准的40mm收口条遮盖。

当前点位/轴线为：客厅支管约6.75m，从 `(10.70,4.95,2.52)` 走至 `(11.20,4.95)→(11.20,4.50)→(6.50,4.50)→(6.50,3.70)→节点`；餐厅支管约1.72m，从 `(7.60,4.34,2.52)` 走至 `(6.60,4.34)→(6.60,3.90)→节点`，最后一段为45°。共享立管中心线约2.334m，之后0.10m水平段以1%到固定排水候选点。为清除实际桥架净距冲突，strong-main 弯点从x=10.90移至x=11.50；弱电AP支路在x=10.80先于y=2.60将横向轴从z=4.48错到z=4.55，再降至y=2.51，穿墙前回到z=4.48。坐标、长度均是模型候选，量房后按实测外径和接口回写。

汇流点落在现有 vanity 投影内。路线没有改 vanity、镜柜或吊顶，Linter仍报告 DN32竖管与现有柜体包络相交约0.61m。该线只有在现有柜底/背部确有可检修的管道服务空间时才可实施；现场必须确认柜体、台盆存水弯、扫地机基站与清扫口净空。空间不足时，当前柜内走法作废，需另提外露短管/局部包管的设计备选并说明成本，不得直接切柜或加长镜柜。

强电主干转折由 `x=10.90` 移到 `x=11.50`，以避开客厅冷凝水段；弱电 AP 路线经一次碰撞复核后保留 `y=2.51m` 低段，并在 `z=4.48→4.55` 作局部平面错位。最新客餐厅送回风管按当前 `config/mep-hvac-coordination.yaml` 复核，客餐厅两条冷凝水支管与强电主干、送回风支管不再报硬包络冲突。路由仍需量房复核实际外径、隔热层、吊架及风管检修面。

## 两个最佳路线候选

| 候选 | 几何与设备依赖 | 优点 | 当前风险 / 条件 | 排序 |
|---|---|---|---|---|
| 自然重力、共用主管 | 本目录平面图及现行配置；φ25 + φ25 → DN32；不启用内机提升泵 | 少一个运行部件，不新增泵电源；一旦厂家确认自然口和共管许可，排水维护简单 | P-SS自然排水口/旁通许可未知；客厅管线露出完成面约65–74mm，需要固定支撑；vanity内立管检修空间未知 | **推荐为首个现场讨论方案**，前提是厂家确认自然口、共管及并发流量；若露管不可接受，转候选二 |
| 内机泵局部提升后连续重力，共用主管 | 暂按两个内置泵出口从2.52m提升至2.75m，再以约1%（客厅）和约3.92%（餐厅）连续落至节点约2.6825m；之后同一DN32干管 | 支管可保持在2.50/2.65m完成面以上，满足隐藏目标；不另加外置泵或降低吊顶 | 需厂家确认至少0.23m有效提升、出水脉冲/流量、同时排水共管、防倒灌及检修方式；按6mm保温假设，客卫支管外包络距2.80m板底约31.5mm、距2.65m完成面约14mm，吊架与管材安装空间须实测；共用立管仍依赖vanity服务空间 | 外观最佳；若厂家或业主不接受自然重力露管，作为替代深化。扬程不足时不得改固定排水点或吊顶来迁就 |

**当前推荐理由**：先按无泵依赖方案与厂家核对是否存在合规自然重力接口、是否允许两个冷凝水支管合流。满足时，这个方案减少运行部件，并保留原吊顶、家具和排水点；若接口不满足，采用内置泵局部提升候选。推荐以“验证后条件成立”为前提，不把任何未知写成已确认。

## 现场/厂家只需确认的资料

1. **空调厂家 / 安装方**：71T2/P-SS与42T2/P-SS逐台实际排水口位置/中心标高；自然重力口是否存在及是否允许作主排；若选泵提升，内置泵在同时排水时可提供的有效扬程与流量（至少覆盖暂定0.23m提升和管路损失）；厂家允许的共管管径、Y接头、止回/防倒灌、存水弯/通气与清扫要求。若不允许合流或并发量超DN32候选，保持固定排水点不动并重新比选独立接管方案。
2. **量房 / 水电 / 暖通 / 木作**：走廊服务带实测梁底、结构板底和客卫/走廊完成面；更新后的送回风管实际外包络与吊架空间；固定候选排水点是否为合法可接的立管/间接排水接口；vanity柜底/背部服务空腔、台盆存水弯和检修口净空。若吊顶腔净空不足，泵提升隐藏候选回退；若vanity无现有检修空间，当前柜内立管回退并另提需业主审核的饰面/家具备选。
