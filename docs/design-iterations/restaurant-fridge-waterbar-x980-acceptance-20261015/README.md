# 客餐厅西墙冰箱 + 干水吧 / 餐桌东移概念定稿

## 本轮结论

业主已确认的**概念基线**：冰箱放在客餐厅西侧候选位，旁设干水吧；1.40 × 0.80m 餐桌南北向，日常四人桌中心 `(9.80, 3.45)`；来客六人时桌椅组整体南移约320mm至中心 `(9.80, 3.77)`，并在桌子南北两端各加一椅。半高柜位置不动，设计基线为 1.42m 上部、北端700mm降低至920mm。

2026-10-16正式落入模型的日常家具位置：餐桌、四把椅子和冰箱的摆位写入 `config/house.yaml`；餐桌地插随桌移至 `(9.80,3.45)`；冰箱门向研究包络改朝东。六人模式、水吧柜体和 1.42m/700mm 半高柜仍为 view-only 预演，未写入正式构件。

**概念审美验收 PASS；功能与施工验收 BLOCKED。** 视觉上，桌体不再横切厨房到客厅的视线；西墙的冰箱与水吧在预演中形成清楚的功能界面；入口仍能读到半高柜的压缩与南向空间释放。六人临时模式在静态几何上没有封住厨房口，但北端椅到推拉门模型面板约50mm，余量偏紧。冰箱43mm实体墙后距、专用电源、墙控件可达、柜体结构和真人并用仍未核验，因此当前属于已落入家具布局的设计模型，尚非施工定稿。

本组为真实正式桌椅/冰箱配置加两个临时几何代理：水吧和1420/700半高柜不属于正式家具源。临时六人图仍引用上面的2026-10-15同机位审查图，其桌椅坐标与正式日常四人布局相差明确的+320mm南移。

- 冰箱机身预演 AABB：x[7.203,7.802]、z[2.567,3.406]、y[0,1.91]。到客餐厅开放边界线 x=7.20 约3mm；其西侧另有客卫东墙，运行时墙体东侧面约x=7.16，冰箱背面到实体墙约43mm。服务组合不是背后完全敞开，但43mm仍不是厂商认可的散热/防护/检修净空。
- 冰箱资料核查：项目候选型号为 HR-518WUFIPZ；已找到美的/华凌官方518系列通用说明书和说明书查询入口，但没有从官方公开资料核实出这个准确型号的门扇、抽屉及安装净空图。业主表中的595mm产品深度与具体型号资料仍需铭牌/官方说明对齐。[官方说明书](https://assets.midea.com/ImageStore/192549/instructions/d5bebb39018f82ccec8b3441680d60e1.pdf) · [美的说明书查询/客服](https://www.midea.com.cn/zh/midea-service)
- 西侧墙体关系已修正：`w_gbath_east` 和 `w_gbath_east_open_vanity` 在当前模型均真实可见，客餐厅开放边x=7.20西侧40mm处是墙体东面x=7.16。冰箱后面约43mm、水吧柜体后约90mm、台面后约40mm；墙后空隙需按厂家散热要求、可清洁和可检修方式深化，不在本轮假设封板。
- 餐桌 AABB：x[9.40,10.20]、z[2.75,4.15]。椅子停放时，水吧前沿至西侧椅最近边约 1050mm；西侧椅向西拉出 450mm 后约 600mm。冰箱门打开、椅子拉出或有人操作水吧时不能按这些静态距离认定可以同时使用。
- 东侧椅向东拉出 450mm 后，其包围盒约到 x=11.15；半高柜西缘约 x=11.3035，余量约 153.5mm。餐厅侧柜门开启、取物及坐人组合状态没有验证。
- 冰箱向东开门 600mm 是研究假设。西侧北椅拉出后到该假设门扇仅约 48mm。没有官方安装图、门铰链/把手/抽屉扫掠和检修路径，不能验收家电使用净距。
- 日常四人要求已确认。固定桌位下，临时5人可在南端加一把椅子，当前模型AABB与推拉门、冰箱/开门假设、水吧和柜体均无相交；固定桌位北端加椅会与推拉门开闭态面板相交。
- 临时6人模式已由业主概念确认：桌椅组保持x不变、整体南移约320mm，北端椅与推拉门最高模型包络约留50mm。独立审美复审为PASS；真实灯具/地插使用、真人坐姿与操作仍未验收。旧的“1.40m三椅/侧25mm、1.60m北侧离门55mm”数据保留在 review-manifest 历史记录中，不再作为日常座位验收条件。
- 六人临时位下，北端椅西缘到600mm冰箱开门假设外缘约1.17m；这是未含人体、门把手、真实机型门弧和搬动过程的静态模型筛查，不代表实际使用净宽。由现有静态 AABB 可判断未直接挡住厨房口；实际同时通行、拉椅和开冰箱的状态尚未通过。
- 干水吧为 view-only 占位体块，不含水槽、真实设备、插座、回路、线缆或人体操作包络。西墙开关和空调面板虽在画面中可见，不能据此判定可触达。

## 未决项和下一步

1. 正式模型当前为日常四人桌心 `(9.80,3.45)`；六人临时模式仍是整体南移约320mm的浏览器预演。实施前核验固定灯具/地插、真人操作和临时搬桌路径。
2. 确认实际冰箱铭牌是否为项目候选 HR-518WUFIPZ；按准确型号核验说明书。600mm 预留深度的起止面也需用官方要求或现场口径明确。
3. 用实际冰箱门扇、把手、抽屉和前拉检修要求复核西墙安装位置；补充新位置的专用插座与可检修路径。
4. 列出干吧设备及同时使用功率，确认插座、回路、台面穿线和墙面控制件可达性。
5. 建立半高柜餐厅侧门扇扫掠，并复核东侧椅停放、拉出、坐人和开门取物组合。
6. 用准确冰箱安装资料复核约43mm背部间距、底部散热、后罩完整性与检修，并明确水吧40/90mm墙后缝的收口/清洁做法。
