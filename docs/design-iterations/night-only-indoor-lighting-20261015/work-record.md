# 夜间仅室内照明与客厅砖向核查

**迭代 ID：** `night-only-indoor-lighting-20261015`

**范围：** 日照模拟进入夜间后的全局光照状态。地砖部分只核对现状并给建议，本轮没有改铺向。

## 已确认的事实

- 太阳高度角不大于 0° 时，太阳方向光已隐藏，`scene.environment` 已清空；原实现仍保留 `AmbientLight=0.15`、辅助 `DirectionalLight=0.06`。
- 日照自动模式在夜间会开启已配置的室内灯；房间开关继续控制各房间。
- 客餐厅当前材料基准是 KT 200×1200 直铺工字错缝。
- 程序纹理的板长边沿纹理 U 轴；地面 U 轴映射世界 X。南侧落地幕墙 `w_liv_south` 从 `(7.20, 9.80)` 到 `(13.40, 9.80)`，也沿世界 X，所以当前砖长边与南窗面平行。

## 用户决定与实现

用户要求夜间关闭全局光、只保留室内照明。夜间现在将 `AmbientLight`、日光方向光、辅助补光全部设为零/关闭，并保持 IBL 为空；室内灯的自动开启、色温、亮度和房间开关不变。日间静态预设不变。

夜间需要保持“日照模拟”开启，再把时间设为夜晚。关闭日照模拟会按既有逻辑恢复静态日间预设。

既有夜间环境光断言已更新为零照明断言；测试套件未运行。

## 地砖方向建议

当前铺向不会形成明显的“从客厅向南窗延伸”的线性引导，主要表现为沿窗墙横向展开。若把视线引向南侧落地窗，建议后续对客餐厅和连续过渡区做 0°/90° 对照：当前方向为东西向；备选为南北向，使砖长边垂直窗面。当前代码没有地面纹理旋转字段，正式改变需先补可控的旋转预演，再由业主比较后定向；本轮没有改动 `config/materials.yaml`、`data/current-scheme.json` 或布局配置。

- 删除旧夜间分支里的两项残余全局照明：环境光 `0.15`、辅助补光 `0.06`。
