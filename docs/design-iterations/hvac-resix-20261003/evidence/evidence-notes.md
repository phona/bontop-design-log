- 结构：5 sheet（空调配置选型表 / 新风设备表 / 名称管理器 / 室内机清单 / 室外机清单）
- 该户配置：客餐厅 55㎡×230 W/㎡=12.65kW → **MJV-80T2/X-TS 8.0kW**；另 27㎡→45T2、次卧 13㎡→28T2 ×2；外机 **MJV-180W-E01-LHIV** 18kW；主卧另配**一拖一风管机**大三匹双出风 KFR-75T2W（6,300 元，含 7m 铜管）
- **单价锚点**：外机 180W = 13,674；内机 28T2/X-TS = 1,754.73、56T2 = 2,024.23、80T2 = 2,601.73；安装人工 1,500/台
- 我们的客餐厅口径对照：该户 55㎡ 配 8.0kW = 145 W/㎡；我们 44.58㎡ 配 9.9kW = 222 W/㎡
  （我们取的是它的**负荷口径 230 W/㎡**，不是它的设备口径——这一点须经销商冷负荷计算书背书）
- 它的连接率算法 = 内机总额定 ÷ 外机额定 = 18.1 ÷ 20 = 0.905（偏保守）；我们 21.6 ÷ 20 = 1.08（设计口径）
