## 1. 云鲸 J65《使用说明书》——超薄上下水版（本户 SKU 的官方手册）

- **原件**：`tmp/capture/jx-manual-2.pdf`（5.4MB，md5 `5275bbcc664fb1fe1d9a870e12817a84`，不入仓）；来源：业主 2026-11-05 提供；版本：PDF 元数据 Title `J65电子说明书-20260514`，24 页。
- **入仓关键页**：p1（封面/适用型号）、p5（基站部件）、p6（摆放与安装步骤）、p7（集尘袋/清洁液步骤）、p9（产品参数）。
- **逐条摘录（结论所依据的原文）**：
  - p1：「适用型号：YJCC034（自清洁充电站：YJCB034S）」——本 SKU 的官方型号坐实（京东页 model 字段 YJCC042 为孤证冲突）。
  - p7 步骤 (8)「集尘袋安装」：「取下自清洁充电站前面板 → 将尘袋按图示方向插入卡槽，注意需插到卡槽底部放置到位 → 将充电站前面板安装到位」；步骤 (7)「添加清洁剂」：「取下自清洁充电站前面板，将清洁剂主仓取出…向外水平抽拉出整个清洁液盒」——**尘袋/清洁液均在基站前面板后取放，全册无顶部开盖机构**（据此证伪 DEC-2026-11-04-R3 的「上盖 25cm」推翻理由，acceptance 开盖项改写）。
  - p9 参数表：「基站尺寸 410×433×280mm；重量约 8.71kg；额定输入 AC 220-240V~；进水压力 0.08-0.8MPa；集尘 450W / 水加热 1350W / 烘干 100W」；「机器人尺寸 351.2×363.5×95mm；重量约 4.97kg；14.4V 锂电池 ≥4900mAh」。
  - p6 步骤 (4)「摆放自清洁充电站」：「确保充电站前方有 0.45 米空旷且无悬崖区域供机器人进出充电站」——官方摆放口径（本户前方净空约 0.98m 满足）。
  - p5 部件图：基站正面仅「可替换清洁滤网 + 清洁底座」，无顶盖/水箱（与水箱版 J64 对照）。
  - p8：「建立地图后请勿移动自清洁充电站，否则需重新建图」。**「整台拉出检修后放回原位是否触发重建图」手册未明示**（引文只规定「移动需重建」，未给复位豁免）——标为待厂家确认/待安装现场操作验证，不得据引文推断免重建（2026-11-06 Codex minor 修正）。

## 3. 石头 Vida 上下水版《智能上下水版使用说明书》（竞品通用性预研）

- **原件**：`tmp/capture/roborock-doc.pdf`（3.6MB，md5 `78d54a20ebe208ca46b742cf067260af`，不入仓）；来源：业主 2026-11-05 提供；版本：PDF 元数据 `4.03.2475-Vida-上下水版-说明书-大陆-搭配Shell 4DA-V3.0-2026.01.19`，24 页。
- **入仓关键页**：p8（B2 放置基站）、p15（基本参数）。
- **逐条摘录**：
  - p8：「在硬质水平地面靠墙放置基站，且预留出高度至少 30.5 厘米，宽度至少 40 厘米，深度至少 120 厘米的空间」；另要求「远离潮湿、有水、狭窄区域」「始终在通风良好的地方使用」——**手册无柜内/嵌入式安装章节**，封闭仓与「远离狭窄/通风良好」措辞有张力（通用性结论的条件性来源）。
  - p15：「机器人 A2950RR；自清洁集尘充电座 EWFD67HRR；进水压力 最大 0.4MPa / 最小 0.1MPa；额定输入功率 热水洗布 1280W / 集尘 520W」；p3：「请勿在机器人、基站上和基站集尘口处放置任何物体，也不要用任何物品（包括防尘罩）将其覆盖」。
  - p14（未入仓）：集尘袋走**顶盖**（取下集尘仓盖板→取尘袋→插卡槽）——头顶加固定层板会堵此路径（甲案否决理由之一）。
  - 手册全册不载基站脚印与机器人高度（通用性判定为「条件性可装」的原因）。
