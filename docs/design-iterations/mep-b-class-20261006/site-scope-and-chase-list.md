## 1. 施工范围口径（本轮新增验收项摘要）

验收标准唯一来源仍是 `config/acceptance.yaml`（phase / id / method / standard / severity）。
本轮新增的 3 个字段（**只增不改旧条目字段**）：

| 字段 | 含义 |
|---|---|
| `when` | 验收时点。取值：`before_covering`（封墙/回填/封板前）、`before_waterproofing`（防水层施工前）、`at_delivery`（设备或柜体安装后复核）。可单值也可列表 |
| `evidence` | 必须留存的照片/记录清单，缺一项即不得进入下一工序 |
| `standard_ref` | 依据的 DEC 全引或规范条款 |
| `item` / `method` / `standard` / `severity` | 沿用既有含义（未改语义） |

### 1.2 与既有验收项的关系

- `check_elec_leb_bonding_list` 是既有 `check_elec_leb`（端子箱存在 + 抽查导通）的**深化版**：
  把口径扩到"清单逐件 + 防水前完成 + 工序交接照片"；`check_elec_leb` 保留，不删不改。

  外移位防水/角阀逐点/全盒零线/浴霸排风出外墙/微蒸烤可插拔/内机检修可及"这些判定口径）。

  本表只验"施工结果是否达到 DEC-2026-10-06-R1/R2 的口径"，不定义新坐标。
