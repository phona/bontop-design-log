# S1 外形修正 V2

## 反馈与核验

业主指出 V1 水吧截图中的 S1 看起来像横放。检查后确认运行时没有横放或转错：物体旋转为 90°，正面朝东；AABB 为宽向沿柜长 312mm、柜深106mm、高280mm，底面接触 y=850mm 台面。312mm 宽略大于 280mm 高，正面本身偏宽。

V1 的程序化外壳只有连续平面塔身和小圆出水口，缺少产品图中明显的外挑上盖与下方凹入接水腔，因此视觉上像一块横向盒子。按业主此前要求的“尽可能贴近真实物品”完善外形表达，不改变物理规格或摆位。

## V2 变更

- 保持用户给定外廓 312×106×280mm、中心 `(7.50,3.64)`、rotationY=90°、台面 y=850mm。
- 用后部直立机身与左右侧颊表达直立主壳体。
- 表现外挑上盖、凹入接水腔、向下出水口、接水盘和正/侧水位窗。
- 不添加真实水箱、供水管、电源、品牌字样或未提供的结构尺寸。
- 冰箱、低柜、EM450、餐桌、半高柜、墙体、吊顶和所有机电点位不变。

## 实质内容审计

- 被替换：V1连续平面塔身/圆点出水口的程序化可见壳体表达。
- 未删除：用户尺寸、既有S1摆位、历史V1截图、S1类型、餐厅水吧/厨房RO对象及此前采购或机电事实。
- 未推翻：S1正面朝东、S1与EM450共用低柜台面、两台设备尺寸、柜体/冰箱/餐桌/建筑坐标。
- 静默失效条件：最终中国SKU外观/方向/尺寸不同于图片和用户给定尺寸；上盖、接水腔或水位窗结构与真实SKU差异明显；后续改旋转/机位却继续引用当前截图。V2只改善外观代理，不证明补水、出水、清洁、散热或维修净空。
