# S1 外形修正 V3

## 业主反馈与重新对照

业主指出V2仍偏离产品效果图。重新对照尺寸图后，V2的“居中凹腔”是错误简化。参考图的关键可见轮廓是：**左侧偏置的出水凹腔、右侧连续主机身与正面竖向水位窗、上部机头跨越全宽**。

## V3 变更

- 以右侧连续主机身和正面水位窗为主壳体。
- 将出水腔和向下喷嘴移到正面左侧，形成偏置的凹入取杯区。
- 上盖跨越312mm全宽；接水盘跟随左侧出水腔偏置。
- 严格保持业主给定 `312W×106D×280H mm` 外廓、中心 `(7.50,3.64)`、rotationY=90°、正面朝东和台面 `y=0.85m`。
- 冰箱、800mm候选低柜、EM450、餐桌、玄关半高柜、墙体、门洞、吊顶和机电点位均未移动或改尺寸。
- 不虚构内部水箱、供水管、实际出水结构尺寸、额定功率或维护空间。
