# S1 外形修正 V4

## 业主反馈与V3复盘

业主在第一人称视角截图后指出S1模型看起来奇怪。重新逐项对照参考商品图与V3配方后，确认主要问题在细部比例和接触关系，不能用“包围盒尺寸正确”代替外形验收：

- V3凹腔侧颊/后壁高116mm，且62mm高的下方面板挡住了凹腔下部，产品图中的高杯仓被压成头部下面的小方洞。
- 接水盘虽有36mm前后深度，但只有12mm厚，近景读成一条薄台阶；盘面也只有整块灰板，没有产品图的排水栅格。
- 8mm宽水位窗的后表面与主机身正面相隔7.5mm，像一条浮贴的棕色直条。
- 14×12mm深色矩形标记不像产品图中的细线标记，且与“外观代理不虚构logo”的范围冲突。
- 外壳全部为直角BoxGeometry，机头、机身和盘边因此显得像几块硬盒拼合。

## V4修正

- 左侧出水仓有效高度由116mm增至184mm，从底部接水盘上方连续开到全宽机头下缘；移除了挡在凹腔底部的下方面板和不准确的小黑方块。
- 接水盘维持在312×106×280mm总包络内，调整为176W×70D×18H mm；加入8条排水栅格和一个小排水凹位。局部比例是依据产品图估读的外观代理，不是实机拆解尺寸。
- 竖向水位窗保留约8×154mm可视尺寸，改为圆头形，并贴合主机身正面；原有7.5mm脱面位置已纠正。
- 底座、主机身、机头、凹腔侧颊和接水盘增加3–10mm程序化圆角；机头顶面加两块浅色面板，表达参考图中的分区线。
- 保持S1外廓312×106×280mm、中心(7.50,3.64)、rotationY=90°、正面朝东、台面y=0.85m不变。柜体、EM450、冰箱、餐桌、半高柜、墙体、门洞、玻璃门和机电点位均不变。

## 实质内容与失效条件审计

- 被替换：V3短凹腔、62mm下方面板、直角外壳、脱离机身的水位窗、薄接水盘和小黑矩形标记。旧V3源码快照与截图保留用于历史对照；V3的“外廓正确”结论没有被推翻，但V3的外观验收结论被本轮业主反馈否决。
- 未删除：S1实例、312×106×280mm尺寸、位置/朝向、台面支承、EM450、低柜、冰箱、RO对象、V1–V3历史截图/运行时证据、任何建筑或机电坐标。
- 新增部分可能静默失效的条件：最终中国SKU的杯仓高度、侧颊、接水盘、水位窗、顶盖分区或表面圆角与本参考图明显不同；这轮细部比例依赖一张透视尺寸图，缺少三视图/CAD，因此只能作为图像近似外观代理。该模型不证明喷嘴流量、杯具尺寸、补水方式、清洁、散热、维护或电气条件。
- 截图中的`hvac:A2:terminal:supply_dining`提示由第一人称屏幕中心射线命中空调送风槽；S1仍保持家具对象ID `furniture:living_dining:mijia_instant_dispenser_s1_preview:15`，两者不是同一个场景对象。
