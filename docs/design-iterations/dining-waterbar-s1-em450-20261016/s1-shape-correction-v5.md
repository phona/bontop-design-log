# S1 外观方向修正 V5：东侧出水、西侧水箱

- **业主要求**：V4看起来像设备横过来；业主明确“出水口朝东，水箱朝西”。
- **问题定位**：V4 的父级对象本来就朝东，局部 `+z` 经 `rotationY=90°` 映射到世界东侧，出水口也在 `+z`。但 V4 把出水仓与主机身沿局部 `x`（旋转后为南北向）排成两块，前后轴上的主机身又居中跨满大部分机深，画面因此读成南北并排。
- **V5几何**：保留父级中心 `(7.50, 3.64)`、`rotationY=90°`、台面 `y=0.85m` 和 `312×106×280mm` 外廓。把局部 `z=-53~-6mm` 定义为西侧后置水箱壳体，把局部 `z=-4~+53mm` 定义为东侧前置出水仓；出水口和接水盘位于局部 `z≈+31~32mm`。顶面盖板也沿局部 `z` 分成西侧水箱盖与东侧出水头盖。水箱和出水仓沿宽度 `x` 大幅重叠，避免再表现成南北两块并排。
- **证据边界**：尺寸和整体外廓来自业主商品图；东/西部件朝向来自业主本轮指示。商品图没有水箱背视图或剖面，因此后壳的宽度、深度和水箱内部/拆取结构是为满足指示而作的外观代理估读，不代表厂家CAD、真实水箱容量或维护方式。
- **替换与保留**：V5替换V4居中的87mm主机壳、沿宽度分开的出水仓以及左右分割的顶盖。V1–V4代码历史、图像、快照、运行记录和评审文件全部保留；V4审美PASS由业主新反馈覆盖，仅作为历史结论。
- **未改变**：没有改S1对象ID、餐厅摆位、朝向角、外廓、台面、EM450、柜体、冰箱、桌椅、墙体、门洞、玻璃、吊顶或任何机电点位。
- **仍待核**：运行时几何只证明模型的静态外廓和空间方向。实际SKU的补水/取水/水箱拆取、清洁、散热、电源与设备同时使用、墙控操作、RO柜内接口仍按 `review-manifest.json` 中既有阻塞项待核。
