## 3. 回路与控制

- 当前口径：不新增独立照明回路；NP-1/NP-2 并入 `lighting_bedrooms_bath`，NP-3/NP-4a/NP-5 并入 `lighting_entry_base`。
- 路径灯本地感应策略仍按各段深化；当前 3D 传感窗/感应带只是外观表达，浏览器尚未模拟人体接近触发。NP-4b 已删除，NP-4a 到柜体 NP-5 的约 5.97m 直线暗区待路径实走和照度复核。客卫三处内置灯取消，`switch_gbath` 手动控制现有平板主灯。可插拔感应灯是入住后的可选补充，不作为一期施工前提。
- 体验层：NP-2 床头小夜灯，触摸+感应双模，留零线与传感器位，后续可入智能联动。
- 与既有 controls 的关系：客房双控（互换后由 `control_parent_bed_door` 改写语义为"门+床头"）**保留**，与起夜灯并存——老人可用按键。
