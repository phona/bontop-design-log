## 问题

`mb_washbasin_cabinet`（x[0,1.10] z[2.91,3.41]）西边缘贴死西玻璃幕墙线（x=0），而 `curtain_master_west`（纱帘+遮光、通高 2.8m、电动）正好落在该角：布帘吸水怕晒，台盆每天溅水，长期有溅水发霉 / 西晒湿帘 / 冷凝水顺帘流到柜侧三个风险。

## 定案方向（方案 A：分段处理）

1. **盆区幕墙格独立成框、无织物**：盆区+站位段（z[2.86, 4.00]，2026-09-02 业主追加南延过台面南缘 0.6m；以实测竖梃为准）增加浅色半透磨砂隐私层，并内嵌哑光暖白 25mm 铝百叶（与主卫湿区同语言），不挂纱帘/遮光帘；磨砂层为室内可逆膜的视觉表达，最终施工按玻璃/物业条件确认。
2. **布帘分段**：纱帘+遮光帘轨道在分界线处断开，z=4.06 起挂通长；z[4.00,4.06] 保留为约 6cm 无构件收口空隙；窗帘盒吊顶通长完整，分段只发生在盒内轨道；帘布第一折用固定钩贴收口端头，不留明显漏光缝。
3. **分界线**：优先借用幕墙自带竖梃；无合适竖梃时不新增独立黑柱，改由百叶边框、布帘轨道端头和 6cm 空隙形成安静收口。**幕墙零附着**（不打孔、不粘胶、不贴膜）。量房后按竖梃位置调整分段点。
4. **柜体（初版已实施）**：东移 5cm 且收宽 1.10→1.05（x[0.05,1.10]），假定玻璃通高；窗带高位（sill≈2.07）成立则量房后回改。
5. **盆居中（意向变更）**：盆心从 x=0.26 东移至柜体中心（≈0.55/0.60），龙头/墙排随移；镜面灯框镜对中挂 `w_mbath_south`。美观（对称，同 GPT 意向图）+ 功能（水点与人远离幕墙 ~0.3m，溅水风险再降）。**前提：原立管位置允许墙排东移 0.29~0.34m**（待量房）。
6. **取消的项**：盆区不设任何织物窗帘；不做内置百叶中空玻璃（开发商幕墙不可更换）；布帘不做"柜体让缝 15cm"变体（两头吃亏，已否决）。
