# 走线设计意图档（R22-v0.5 起维护）

> 目的（业主 R22-v0.5 指令六）：现场提出变更时，按设计意图评估，不只比较坐标。
> 每条记录：设计目标 / 不可牺牲约束 / 可调参数 / 关键依赖 / 现场变更时优先比较的替代方案。

## 冷凝水（condensate-living / condensate-dining，共网）

| 项 | 内容 |
|---|---|
| 设计目标 | 管线隐藏、排水可靠、不破坏客卫开放洗漱区空间品质 |
| 不可牺牲 | 排水接点 (6.70,3.70,0.10) 不动（R5 固定断言）；1% 坡度契约、重力管禁上弯；走廊净高 2.50 红线（R5） |
| 可调整 | 平面走向（本轮已用：S3/S4 改贴 w_gbath_east_open_vanity 柜内 x=7.00）；局部标高；支撑/包管方案 |
| 关键依赖 | P-SS 泵出口位/扬程（厂家，#39）；走廊服务带梁底实测（#41，卡抬升选项）；开放洗漱柜体深化（隐藏段可实施性） |
| 现场变更时的替代序 | ① 柜内隐藏维持（现案）② 局部降吊顶管槽（走廊段）③ 抬升改重力入吊顶腔（仅当梁底实测允许）④ 接点位置复核（若 R5 断言被推翻）——按序比较，①不可行才看② |

**需业主批准的红线**：任何明显外露管线、降低吊顶、改变固定排水接点。

## 走廊干线（强电 / 弱电 / 冷媒 / 送回风）

| 项 | 内容 |
|---|---|
| 设计目标 | 六系统在走廊满吊与边吊带内有序并行，交底可解释、量房后可回归 |
| 不可牺牲 | 完成面 2.50 净高红线（R5）；梁带内 ≤2.60（中心口径，实体口径待定 B1）；送回风风管体优先（大管让小管） |
| 可调参数 | 各系统走廊 z 轴位（本轮弱电 4.55→4.38）；层高相对关系（Z 表候选，待 B1/B3）；局部偏轴 |
| 关键依赖 | 龙骨构造（#73）；回风行/送风行定版（并行 HVAC 批）；风管体包络 |
| 现场变更替代序 | 平面偏轴（优先）→ 局部翻弯（仅电管）→ 层高微调（±0.03 内）→ 换走廊行位（最大动作） |

**需业主批准的红线**：降吊顶、改变梁带内标高上限口径（2.60 中心 vs 实体）、走廊行位大改。
