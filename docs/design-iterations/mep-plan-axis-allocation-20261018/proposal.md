## 3. 龙骨净距校核（R22-v0.3-1，阻塞 B1）

### 3.1 强电 2.59 候选的净距事实

- 暂估龙骨带 = 石膏板面 2.50 + 副龙骨 + 主龙骨 ≈ **2.50–2.58**（假设框，pending-site-data #73，未选型未实测）。
- 候选中心 2.59 − φ20 半径 0.010 = 管底 **2.58** = 暂估龙骨带**上缘**。
- **结论：净距 = 0mm（恰好接触）。** 在「最小净距标准」与「支撑方式（管卡/支架/借龙骨固定）」确定前，2.59 **不标记通过**（维持候选待验证）。
- 同理复核其余候选层：弱电 2.66 管底 2.65（龙骨带上方 +70mm ✓ 数字上）；冷媒 2.73（φ19，底 2.7205）✓——但三层的共同前提仍是 #73 的真实构造，假设框一变全部重算。
