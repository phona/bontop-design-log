## 2. 审计任务 B：condensate-living 完整路径（R22 §四）

分段路径表：[condensate-path-v04.csv](./condensate-path-v04.csv)（4 段，全程 4.65m 水平 + 2.16m 竖降）。

### 2.1 五项核实的结论

1. **P-SS 真实设备类型**：/P-SS 为已购美的双出风内机的**内置排水泵选件**（materials.yaml #39「6 台双出风内机全带泵」）——
   **泵的存在性是真实数据（合同级）**；但**泵出口坐标、扬程、允许接驳方式均未核**（#39 vendor_verification_pending、
   electrical.yaml L129）→ `from_height 2.35`（S1 起点）是**未确认假设**，不是设备参数。
2. **泵送段/重力段边界与 1% 契约适用范围**：泵内置时出口之后即重力段（S1 末至 S4）；S1 接驳段实算 26.7% 陡落
   （0.15m 内落 40mm）——**1% 不是逐段契约**：lint 实现为「单调非升 + 全线偏差 ±50%」的 summary 检查，
   接驳段与竖直段不单独限值。v0.3 文字「1% 坡全程单调已验」据此精化（§3 差异 D4）。
3. **文档转折点与配置一致性**：reason 文字（10.30,4.60）→(6.70,4.60)→(6.70,3.70)→竖降，与 via/端点逐点一致 ✓。
4. **数字吻合性**：S2 长度恰为 3.60m、2.31→2.27 落差 40mm → 坡度 1.111%，unsupported_span 报文
   「3.60m … (10.30,2.31,4.60)→(6.70,2.27,4.60)」与几何**逐位吻合** ✓。
5. **unsupported_span 的确切含义**（按源码，非字面“无支撑”）：该段全部采样点**三类模型依托均不命中**——
   y>0.35（非垫层）、y<surface 2.50（不在吊顶腔内）、距最近非 suppress 墙 >0.25m（走廊中部）。
   真实世界里“板下明露管”可以有第四类依托（局部降吊顶管槽/明装线槽）——**那是不在模型里的依托，
   属于 B2b 支撑设计问题，不是几何不存在**。

## 6. 统一高度与净距规则（R22 §六）

六概念定义及其在三个节点上的现状：

| 概念 | 定义 | 现状 |
|---|---|---|
| 中心标高目标 | 设计意图的管中心 | 各 route y 字段 |
| 中心允许范围 | 规则允许的中心区间（如 A 区 ≤2.75、B 区 2.70–2.76）——**区间按中心还是边界，未定义**（B–B 案例见下） | 口径未定 |
| 材质+保温实体包络 | 中心 ± (半径+保温) | 电管可算；**冷媒保温未定** |
| 并管整体包络 | 多管排列后的外接包络 | **未声明**（outdoor/washer、condensate 双管） |
| 建筑构造实体边界 | 板面/龙骨带/梁体/原顶 | 板与原顶真实；**龙骨带为假设框（#73）**；梁底 inferred ±0.15 |
| 支架与安装空间 | 管卡/吊架/检修操作余量 | **全未定**（B1/厂家） |

四项特别复核：

1. **强电 2.59 × 龙骨带**：管底 2.58 = 带上缘，净距 0mm → 不通过（R22-v0.3-1 维持）。
2. **冷媒 2.73 × A 区上限与送回风**：中心 2.73 ≤2.75 ✓（中心口径）；顶包络 2.7395+保温（≥2.75 上限冲突待保温定）；
   回风风管体 2.62–2.82（若按 ac/air 包络语义）与冷媒 2.72–2.74 区间重叠——**平面交叉清单未回归（B3）**。
3. **B 区完成面 2.65 时 2.74/2.755 的实体净空**：2.74 → 管底距板 80mm、顶距上限口径 10mm（边界读法）/−10mm… 
   2.755 顶包络 2.765：顶边界读法超 5mm、中心读法在限内——**两种读法结论相反，口径未定前不可判定**（v0.3-2 维持）。
4. **梁带 2.60**：中心口径（§4 of v0.3 维持），实体口径公式待净距标准。

净距标准：**未采标**。ledger 中出现的 0/17.5/32.5/70/87.5mm 一律是“计算所得候选值”，不构成合规判定；
任何规范/厂家值的采标须记录来源与适用范围后另行登记。
