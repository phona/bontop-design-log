## 0. 一句话结论

**可耐福蓝臻 50 全轻钢龙骨 + 千年舟 ENF 9mm 欧松板满铺打底 + 可耐福 C7 石膏板封面**；平顶 155 元/㎡、窗帘盒 105 元/米、线型灯安装 10 元/米、普通灯孔免费（均包工包料，辅材在内）。

这是一版**偏扎实的中高配方案**：不是最低成本，而是用少量材料成本换施工容错、节点可靠性和后期固定便利。详见 §4。

施工报价（§3.3，代码实算）：边吊 **21.475m × 160** + 满吊平顶 **7.390㎡ × 155** + 窗帘盒 **17.85m × 105** = **¥6,455.70**，未含厨卫铝扣板、晾衣架吊顶、线型灯。

价格判定（§2.3/§4.1）：材料参考成本 **98～120 元/㎡**；按施工方分形态口径反推材料额度 **122.71 元/㎡**（C11 的 95 是"全按 155 元/㎡"的旧算法，低估了边吊），**略高于上限 2.71 元/㎡**——材料这一项基本够。

**两条口径告警**（代码会显形，不许混算）：

1. **规格差一倍**：家装 1200×2400 = 2.88㎡/张，工程 3000×1200 = 3.6㎡/张。47.70 元/张按家装规格算是 16.6 元/㎡、按工程规格算只有 13.3 元/㎡——所以工程价的 47.70/53.30 只登记、不参与折算。
2. **边龙骨取的是上界口径**：3.06 米/㎡ 是**全部分区周长**，而真实边龙骨只沿墙与错台边缘（同标高相接的内部边不需要）。本案 10 个分区、边吊/服务带/窗帘盒犬牙交错，实际用量介于「墙边+错台边」与这个上界之间，须现场核定。上界口径对成本估计是**保守方向**（偏高），但已经暴露出「大平顶经验值 0.4 米/㎡」在本案完全不适用。

**配置字段**（`config/ceiling-material-cost.yaml`，供后续会话改数用）：

| 字段 | 含义 |
|---|---|
| `area_basis` | 对账面积取 takeoff 的哪个工艺类别（当前 `gypsum_board`）；改局部加强方案后可能要分开估 |
| `items[]` | 材料清单；`basis` 决定计价基准：`per_sheet`（按张，靠 `sheet_size_m2` 折算）、`per_sqm`（直接按面积）、`per_metre_derived`（按米，靠 `usage_assumptions` 折算）、`per_metre_unconverted`（按米、缺用量，只登记） |
| `items[].observations[].component` | 型材米价归属哪个构件（主/副/边龙骨），靠它匹配 usage_assumptions |
| `usage_assumptions[]` | 龙骨用量口径（米/㎡）：前两条是规范间距区间（`status: unconfirmed`），第三条 `source: takeoff_perimeter` 由代码从 takeoff 周长实算，手抄会被 fail closed 拦下 |
| `items[].observations[]` | 价格证据台账：`grade` + `rate`/`min`/`max` + `unit` + 观察级 `sheet_size_m2` + `source` + `observed_at` + `caliber`。**没有台账的价格不许入库** |
| `contractor_rates` | 施工方转述的两个单价（纯人工 / 包工包料）；材料额度 = 两者之差，代码现算 |

### 2.4 材料成本估算结论（可直接引用的一句）

> **材料成本估算：按可核实价格与规范用量算是 98～120 元/㎡；施工方包工包料按分形态口径（边吊 160 元/米 + 平顶 155 元/㎡）反推，材料额度 **122.71 元/㎡**，略高于上限 2.71 元/㎡。最终以本地实际进货单及现场材料型号为准。**

**结构性看点（C11 修正）**：两张板（欧松板 27～29 + C7 26～30）= **53～59 元/㎡**，龙骨逐构件折算 **36～45 元/㎡**，辅材 + 损耗 **9～16 元/㎡**——三项合计 98～120。业主原来给的龙骨 18～28 元/㎡ 偏低，差在**边龙骨**：本案 10 个吊顶分区、周长合计 70.95m ÷ 23.222㎡ = **3.06 米/㎡**，而行业算例的 0.4 米/㎡是按 10m×10m 单个大平顶算的——**分区碎让边龙骨用量涨到经验值的 7.7 倍**。这是模型算出来、肉眼看不出来的成本。

**材料额度为什么不是 95 而是 122.71（C12 修正 C11）**：C11 用「155 − 60 = 95 元/㎡」算额度，前提是**全部石膏板都按 155 元/㎡**。施工方真实口径是边吊按米、平顶按㎡，而边吊是 0.5～0.9m 宽的窄带——按米算下来石膏板部分包工包料 ¥4,581.45（197.31 元/㎡）、纯人工 ¥1,731.90（74.75 元/㎡），**材料额度 = ¥2,849.55 = 122.71 元/㎡**。比 95 高出的 27.71 元/㎡ 全是边吊比平顶贵带来的。

### 3.1 为什么不能直接把 155 套进报价面板

报价面板的「吊顶板面」行数量 = 总净面积 − 窗帘盒 = **40.668 ㎡**，其中除了本案的石膏板 23.222 ㎡，还含**厨卫铝扣板 16.366 ㎡**与**晾衣架吊顶 1.08 ㎡**——即 **17.448 ㎡ 不该由本案报价承担**。若真按这家的价计，面板会得出 155×40.668 + 105×17.85 = **8,177.73**，比本案真实适用范围多 **2,704.13 元**。这就是典型的「数字对、口径错」。因此 `DEC-2026-10-08-C08` 起就把混合口径行标成**超出范围**（`out_of_scope`），报价总额只按本家真实覆盖的行计算（C12 后为 ¥6,455.70），`active` 也**不切**——切了会把预算人工整体改写，须等书面分项报价单。

### 3.3 分形态计价（DEC-2026-10-08-C12）：边吊按米、平顶按㎡

施工方的口径是**两套单位**：边吊 160 元/米、平顶 155 元/㎡。这不是一回事——一条 0.5m 宽的边吊按米算是 320 元/㎡，是平顶的两倍。混成一行「155 元/㎡」会让总额差 ¥700～1,100。

做法：`config/ceiling.yaml` 的每个石膏板分区显式声明 `pricing_form`，代码只读不推断（猜错的代价就是这 ¥700+）：

| `pricing_form` | 分区 | 量 |
|---|---|---|

### 3.2 业主自家两个口径的差额（可自检的数字）

| 口径 | 计算 | 金额 |
|---|---|---:|

| **隐含材料 + 辅材** | 差额 | **3,187.80 ≈ 137.28 元/㎡**（对石膏板 23.222 ㎡） |

这 137.28 元/㎡ 就是「龙骨 + 9mm ENF 欧松板满铺 + C7 石膏板 + 吊杆吊件 + 自攻钉等辅材」的隐含额度。**本项目没有对它做过任何南宁市场取证，不做贵/便宜的结论**；核验方式是向施工方要**分项报价单**（龙骨按 ㎡ 或按套、欧松板按张、石膏板按张、吊杆按根、辅材按项），逐项对着这 137 元/㎡ 拆。

**注意这个 137.28 与 §2.4 的 95 元/㎡ 不是一回事**：137.28 把窗帘盒的材料也摊进了石膏板面积（窗帘盒包工包料与纯人工差 55 元/米，摊到 23.222㎡ 上是 42.28 元/㎡）；95 元/㎡ 只用业主口径的平顶价差。两个数放在一起看，说明窗帘盒那一档的材料额度（55 元/米）也偏宽——核验窗帘盒时分项单要单独拆。

## 4. 方案评价

当前方案属于**偏扎实的中高配**。

**优点**

- 全轻钢结构稳定性较好；
- 欧松板满铺后固定点自由度高；
- 对中央空调风口、线型灯、窗帘盒等复杂节点友好；
- 石膏板不直接承担大量固定需求；
- 后期安装灯具、轨道等容错更高。

**缺点**

- 相比「轻钢龙骨 + 单层石膏板」材料更多；
- 吊顶自重增加；
- 欧松板全铺存在一定堆料属性；
- **普通大平顶区域的性能收益有限**。

**定位**：不是最低成本方案，而是「增加少量成本，换施工容错、节点可靠性和后期固定便利」。

### 4.1 价格合理性判定（C09 → C10 可核实价 → C11 龙骨用量 → C12 分形态口径）

**三个口径给出三个结论，这本身就是答案**：

| 口径 | 材料区间 | 额度判定 |
|---|---:|---|
| 业主转述单价（全按 owner_reported） | 70～115 元/㎡ | 95 元/㎡ → `within_range` |
| C11：可核实价 + 龙骨用量，额度仍按「155 − 60」 | 98～120 元/㎡ | 95 元/㎡ → `below_range`（低 3 元） |
| **C12（现行）：额度按施工方分形态口径算** | 98～120 元/㎡ | **122.71 元/㎡ → `above_range`（高 2.71 元）** |

结论（C12 修正后）：

> **材料这一项基本够，甚至略宽。** 施工方按分形态口径（边吊 160 元/米、平顶 155 元/㎡）报出的价，反推到材料上是 122.71 元/㎡，比可核实区间上限 120 还高 2.71 元。C11 说的「差 3 元不够」是当时假设全部按 155 元/㎡ 算造成的——那个假设把边吊的溢价算丢了。

代码判定（`GET /api/ceiling/material-cost`）：`verdict: above_range`、`slackVsMin: +24.71`、`slackVsMax: +2.71`、`contractor.basis: forms`（带逐形态明细：边吊 ¥2,147.50 + 平顶 ¥702.05）。

**材料区间为什么从 70～115 抬到 98～120（C10/C11 的账）**：

1. **龙骨 18–28 → 36–45**：米价可核实（8.50/6.34/4.10），但业主没给用量；按规范间距折算后反而更高，主要因为本案分区碎、边龙骨 3.06 米/㎡（经验值 0.4 的 7.7 倍）。
2. **C7 16–30**：无公开成交价，用同级耐潮/耐水板旁证；业主给的 45–70 元/张低于可核实的 75–85。
3. **欧松板 27–47 → 27–29**：业主给的 140 元/张上限没有可核实来源。

**这条结论的三个前提**（缺一条就不成立）：

1. 三样主材按 §2.2 兑现（进场验品牌/型号/等级，不接受同档替换）；
2. 122.71 元/㎡ 是**材料额度**，不含施工方利润与风险金，也不含超高费、垃圾清运与成品保护——若这几项也算进 160/155 里，材料额度会被压缩；
3. 龙骨用量按规范间距（主 1000mm / 副 400mm）且**不加横撑**；若现场要求加横撑（间距 600–800mm），再加约 8～11 元/㎡。

**证据分布决定结论强度**：五项里只有**欧松板是 verified**，C7 与龙骨是 comparable 旁证，辅材/损耗是业主口径。所以这条判定只能回答「报价结构合不合理」，**不能替代进货单**。

**这条结论的正确用法**：余量只有 2.71 元/㎡（2%），一次边龙骨用量超标或 C7 按更高档拿货就能吃掉。它的价值不是"证明报价便宜"，而是**把验收重心压到进场材料上**——龙骨是不是蓝臻、欧松板是不是 ENF、C7 是不是真 C7；这三样对不上，2.71 元的余量瞬间变负。

## 5. 性价比备选方案（欧松板局部加强）

若需继续压预算，可调整为：

> **可耐福蓝臻 50 轻钢龙骨 + 可耐福 C7 石膏板全屋 + 千年舟 9mm ENF 欧松板局部加强**

欧松板仅用于：窗帘盒、线型灯槽、中央空调长风口、回风口/检修口、需要安装较重物件的位置、复杂转角、未来可能需要打螺丝固定的位置。普通大平顶直接「轻钢龙骨 + C7 石膏板」。

**差价判据（业主口径）**：

| 局部加强比满铺便宜 | 结论 |
|---|---|
| 约 10～15 元/㎡ | **没必要削减**，保留当前满铺方案 |
| 约 20～30 元/㎡ 以上 | 局部加强性价比更高，值得降配 |

**把判据换算成钱**（对石膏板 23.222 ㎡）：便宜 10 元/㎡ ≈ **232 元**、15 元/㎡ ≈ **348 元**、20 元/㎡ ≈ **464 元**、30 元/㎡ ≈ **697 元**。也就是说，这个降配决策的**全部价值不到 700 元**——不值得为它牺牲节点可靠性，也不值得反复议价。正确顺序是：先按 §6 验收施工节点，节点都过再谈这 700 元。

## 6. 施工重点（现场验收清单）

**材料品牌不是最终质量决定因素**，现场逐条检查：

1. 龙骨间距正常，**不得为省材料明显放大间距**；
2. 吊杆、吊件安装牢固；
3. 大平顶整体水平、顺直；
4. 石膏板**错缝铺设**，避免十字通缝；
5. 转角位置避免简单直缝处理；
6. 空调风口、回风口、检修口周围加强；
7. 线型灯位置**提前做基层**，不允许吊顶完成后随意切割；
8. 窗帘盒提前预留轨道固定基层；
9. 石膏板自攻螺丝间距均匀，**不得打穿纸面**；
10. 水电、中央空调、灯线全部确认完成后才能封板；
11. **封板前拍摄吊顶内部照片归档**。

## 7. 中央空调节点

本项目客餐厅存在多台中央空调内机和长条风口（成交配置见 `DEC-2026-10-04-R1` 一拖六与 `DEC-2026-10-05-R1` 逐房映射），属于吊顶重点接口。

**施工顺序**：

```
确定内机位置
 → 确定吊顶尺寸
 → 确定出风 / 回风 / 检修口
 → 龙骨避让及加强
 → 欧松板基层
 → 石膏板封面
 → 开口
 → 百叶安装
```

**铁律**：木工**不得脱离空调施工图自行决定风口尺寸**。`config/ceiling.yaml` 的 `ac_*` 是非实心分区、不计量，只为协调关系留痕；机身外廓、边吊内净空与风口适配以厂家安装图与现场复核为准。
