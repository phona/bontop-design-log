# 和萃 701 — 点位配置与 3D 可视化系统

> 本文档设计一套**配置驱动的点位系统**：用 YAML 定义插座/水管/吊顶的位置，在 3D 场景中渲染成可交互的标注。第一人称走进去看、发现问题、当场改配置。
>
> 不是出一套死图纸，而是搭一个**边走边看的机制**。
>
> Phase 1（可视化增强）见 `2026-07-23-visualization-design.md`
> Phase 4（采购监理系统）见 `2026-07-23-procurement-supervision-design.md`
>
> **标注名：** 所有房间显示名称从 `model-geometry.yaml` 的 `rooms[].name` 读取，不改代码只改配置。

## 二、机制设计

### 2.1 配置层

```
config/
├── electrical.yaml    ← 插座/开关点位（房间+墙面+坐标+高度）
├── plumbing.yaml      ← 给水/排水点（区域+类型+坐标）
└── ceiling.yaml       ← 吊顶分区+晾衣架
```

示例格式（electrical.yaml）：

```yaml
- id: sock_tv_01
  room: living_dining
  wall: w_st_east
  type: socket
  x: 7.20
  z: 5.80
  height: 0.3
  count: 4
  note: "电视墙插座，含USB×2"

- id: switch_living_01
  room: living_dining
  wall: w_ent_kit
  type: switch_2way
  x: 7.20
  z: 4.30
  height: 1.3
  note: "客厅灯光双控（入户侧）"
```

`wall` 字段引用 `model-geometry.yaml` 中 `walls[].id`。标注渲染时检查坐标是否在对应墙段范围内，偏差超过墙厚自动吸附到墙面。

### 2.2 可视化层

`app/src/render/annotations/AnnotationRenderer.ts`

- 读取所有点位配置，在对应墙面/地面位置渲染 3D 图标
- 图标样式：
  - 插座：小方块 + 悬浮标签 "📌 4位插座（含USB）"
  - 开关：小圆片
  - 水龙头：蓝色圆点
  - 地漏：灰色圆环
  - 吊顶区：半透明平面覆盖层
  - 空调内机：天花内机简化模型（方形薄片，标注 "❄ 客厅内机"）+ 冷媒管走向虚线
- 空调内机位置从 `config/house.yaml` 的 `hvac` 配置读取（房间+机型），渲染在对应房间吊顶高度（距天花板 5cm）
- 第一人称模式下：距标注 < 2m 显示详情标签，> 5m 隐藏；距离从相机到标注位置计算
- 俯视图：快捷键 `P` 切换标注图层（电气/给排水/天花）
- 图标大小可调，不干扰正常场景浏览

### 2.3 问题检测

结合点位配置 + 现有模型，自动检测常见问题并在场景中高亮：

| 检测项 | 方式 |
|--------|------|
| 插座在柜子/床后面 | 检查点位坐标 vs furnishings 占位 |
| 给排水穿过承重墙 | 检查管路 vs w_type=structure |
| 空调内机与吊顶冲突 | 内机高度 vs 吊顶底面高度 |
| 同一墙面点位打架 | 两个点位间距 < 20cm |

检测结果在场景中用红色标记 + 右侧面板列出问题列表。

## 三、方案演化机制

1. **初稿**：配置示例写入 YAML，场景中标注
2. **迭代**：改配置 → 重启 → 场景更新
3. **定稿**：截图/标注给施工队看
4. **变更**：入住后改 YAML 即可

**任何时候改都只需要改 YAML。代码只执行配置，不推断。**
