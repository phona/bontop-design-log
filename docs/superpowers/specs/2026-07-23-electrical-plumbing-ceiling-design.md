# 和萃 701 — 水电天花配置系统

> 本文档设计一套**配置驱动的图纸生成机制**，不是一锤子方案。
>
> 核心思路：你家的插座、水管、吊顶不是死图纸，而是 YAML 配置。改一行配置，3D 标注和 SVG 标签图自动更新。
>
> Phase 1（可视化增强）见同目录可视化增强 spec。

## 二、机制设计

### 2.1 配置层

新增三个 YAML 配置文件，定义点位和路由：

```
config/
├── electrical.yaml      ← 插座/开关/灯光点位
├── plumbing.yaml        ← 给水/排水/热水回路
└── ceiling.yaml         ← 吊顶分区+隐藏式晾衣架
```

每个配置严格 schema，代码只读取不推断。

### 2.2 渲染层

新增 `app/src/render/annotations/` 目录：

```
app/src/render/annotations/
├── ElectricalAnnotation.ts   ← 读取 electrical.yaml → 在 3D 场景标插座图标
├── PlumbingAnnotation.ts     ← 读取 plumbing.yaml → 标水管走向
├── CeilingAnnotation.ts      ← 读取 ceiling.yaml → 标吊顶范围
└── DrawingExporter.ts        ← 输出 SVG 标签图（俯视图叠加标注）
```

### 2.3 交互

- 3D 场景中：插座/水管图标悬浮在对应墙面位置，鼠标悬停显示详情
- 俯视图模式：按 `P` 切换标注图层叠加（电气 / 给排水 / 天花）
- 配置变更：重启 dev server 自动重载（已有热重载逻辑）

## 三、初始配置内容

以下为初始点位方案，后续随时可改。

### 3.1 电气点位 (electrical.yaml)

#### 通用原则

- 每房间至少 2 面墙有插座，防家具遮挡
- 床头双控开关
- 厨房台面插座带独立开关
- 卫生间带防溅盒
- 儿童房插座离地 1.2m，其余 0.3m
- 每房间预留网口

#### 客厅（35.2㎡）

| 位置 | 点位 | 数量 | 说明 |
|------|------|------|------|
| 电视墙（西墙 x=7.20） | 插座+网口 | 4+1 | 电视/音响/预留，USB×2，暗埋 50mm 穿线管 |
| 沙发两侧 | 插座 | 各2 | 手机充电+落地灯 |
| 东南角 | 插座 | 1 | 饮水机 |
| 餐桌旁 | 插座+地插 | 1+1 | 电磁炉/火锅 |
| 南幕墙 | 插座 | 1 | 电动窗帘预留 |
| 吊顶内 | 插座 | 1 | 空调内机 |
| 入户门侧 / 走廊入口 | 开关（双控） | 各1 | 客厅灯光 |

#### 其他房间

（后续在讨论中逐房补充）

### 3.2 给排水 (plumbing.yaml)

| 区域 | 给水 | 排水 | 备注 |
|------|------|------|------|
| 主卫 | 洗手台+淋浴+马桶 | 全部下水 | 普通马桶 |
| 客卫 | 洗手台+淋浴+马桶 | 全部下水 | 普通马桶 |
| 厨房 | 洗菜盆+净水器 | 台盆下水 | 台下净水器预留插座+柜体空间 |
| 生活阳台 | 洗衣机+烘干机 | 地漏 | 叠放，同一排水 |
| 入户花园 | 水龙头 | 地漏 | 浇花/洗拖把 |

**热水系统：** 零冷水燃气热水器（预埋回水管），主卫/客卫/厨房三处循环。

### 3.3 天花吊顶 (ceiling.yaml)

| 区域 | 做法 | 厚度 |
|------|------|------|
| 客厅 | 局部吊顶（走管区） | 25~30cm |
| 走廊 | 吊平 | 同客厅 |
| 厨房 | 集成吊顶（铝扣板） | — |
| 主卫+客卫 | 集成吊顶 | — |
| 所有卧室+书房 | 周边石膏线 | — |
| 入户花园 | 防水涂料 | — |

**隐藏式晾衣架：** 嵌入客厅南侧吊顶内。预埋加固板承重，预留零火地三线电源。推荐产品：晾霸 Q3/Q5、邦先生 M33、好太太 D-3138。

### 3.4 空调

**选型：** 美的理想家 III 一拖五（A2 方案）
- 外机：西平台（VRV 设备平台）
- 内机：客厅+主卧+西南次卧+书房+儿童房
- 预算：2.8~3.0 万

详见 `docs/hvac_options_analysis.md`。

## 四、方案演化机制

1. **初稿阶段**（现在）：上面这些点位是第一次 draft，后续讨论中修改
2. **确认阶段**：去逛建材、看样板间后，调颜色/位置/品牌
3. **施工阶段**：水电工进场前定稿，定稿后输出 SVG 图纸给施工队
4. **变更阶段**：入住后想改？改 YAML → 重启 → 图纸更新

**任何时候改都只需要改 YAML，代码不动。**
