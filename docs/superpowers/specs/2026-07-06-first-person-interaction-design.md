# Spec 3：第一人称漫游 + 对象交互

> **目标**：让用户能以第一人称走进房子里体验方案，像 Minecraft 一样选中物体查看决策信息。
> 
> **依赖**：Spec 2（App 3D 场景 + 基础漫游）

---

## 1. 范围

### 包含

- 第一人称相机控制（WASD + 鼠标）
- 玩家胶囊体碰撞检测
- 轨道/第一人称模式切换
- 屏幕中心准心
- 准心对准物体时显示提示
- 选中物体信息面板：当前选项、替代方案、价格差异、风险
- 总览菜单：当前方案、预算、决策记录、归档列表

### 不包含

- 预算/风险计算逻辑本身（Spec 4 提供后端接口）
- 归档/diff/恢复（Spec 4）
- 复杂规则引擎（Spec 4）

---

## 2. 交互模型

类似 Minecraft 创造模式：

- `WASD`：前后左右移动
- 鼠标移动：控制视角
- `V` 键：切换轨道/第一人称
- 鼠标左键：选中准心对准的物体
- `Esc`：释放鼠标指针

### 2.1 模式切换

轨道 → 第一人称：

- 默认在 **入户花园地面中心** spawn
- 面朝客餐厅方向
- 如果当前轨道相机位置在合理地面高度（y < 3m），可优先用该水平位置
- 玩家眼睛高度 1.6m

第一人称 → 轨道：

- 退回到第三人称轨道视角
- 目标点保持为当前位置或选中物体
- 相机动画持续 0.5 秒，过渡期间任何用户操作（WASD、鼠标视角、再次按 `V`）立即打断动画并恢复响应

### 2.2 Pointer Lock

- 按 `V` 进入第一人称时请求 pointer lock
- 浏览器拒绝时显示提示："请允许鼠标锁定以使用第一人称"
- `Esc` 释放 pointer lock，但仍保持第一人称；鼠标可点击 UI
- 再次点击画面或按 `V` 重新请求 pointer lock

### 2.3 玩家实体

- 胶囊体：半径 0.3m，高度 1.7m
- 眼睛高度：1.6m
- 移动速度：约 2m/s

### 2.4 碰撞检测

- 使用房间墙体和平台边界构建 AABB 障碍物
- 玩家移动前预测新位置，检测是否与障碍物相交
- 如果相交，沿滑动方向修正
- 当前户型均为轴对齐房间，AABB 足够

## 3. 准心与物体选择

### 3.1 准心

屏幕中心固定十字/点准心。

### 3.2 悬停提示

准心对准可交互物体时：

- 显示物体名称
- 鼠标样式变化（可选）

### 3.3 点击选中

鼠标左键点击后：

- 该物体被设为 `selectedObject`
- `POST /api/view-context`
- 打开/更新信息面板

---

## 4. 物体信息面板

选中物体后显示：

### 4.1 基本信息

- 对象名称（如“主卧”）
- 对象类型（room / outdoor-unit / indoor-unit / wall / floor）
- 所属房间

### 4.2 相关决策

根据 `config/design-rules.yaml` 的 `objectMapping`，列出影响该物体的话题：

- 该房间当前生效的选项（全局 default + roomOverrides）
- 选项描述和价格
- 可切换的替代方案
- 切换范围选择（两个互斥动作，必须明确选择其一）：
  - **仅当前房间**：设置该房间的 `roomOverrides`，仅影响当前房间
  - **所有房间**：修改全局 `default`，影响所有未单独覆盖的房间

### 4.3 成本影响（可选）

切换某个替代方案时，如果 Spec 4 的预算接口已就绪，显示预算变化（来自 `/api/budget`）。

### 4.4 风险提示（可选）

如果 Spec 4 的风险接口已就绪，来自 `/api/risks`，显示与该物体/话题相关的风险。

---

## 5. 总览菜单

通过快捷键/按钮唤出，半透明显示：

- **当前方案**：各话题当前选择
- **决策记录**：最近几次选择变更（来自 `/api/decisions`）
- **预算**：总预算和分类 breakdown（来自 `/api/budget`，Spec 4 提供）
- **风险提示**：当前方案风险列表（来自 `/api/risks`，Spec 4 提供）
- **归档方案**：已保存的方案名称列表（来自 `/api/schemes`，Spec 4 提供）

唤出方式：

- 快捷键 `M`（`Tab` 与浏览器默认焦点导航冲突，不推荐；如需兼容可保留 `Tab` 但需提示用户）
- UI 按钮

## 6. 数据流

### 6.1 第一人称移动

```text
用户按住 WASD
  → FirstPersonController 计算移动方向
  → CollisionDetector 检测碰撞
  → 如果合法，更新相机位置
  → HouseScene 渲染
```

### 6.2 准心选中

```text
用户鼠标对准物体
  → Raycaster 从屏幕中心发射射线
  → 命中最近可交互物体
  → 显示悬停提示
  → 点击后更新 selectedObject
  → POST /api/view-context
  → 打开信息面板
```

### 6.3 切换替代方案

```text
用户在信息面板点击替代方案
  → StateSync PATCH /api/scheme/current
  → 后端更新 CurrentScheme
  → HouseScene 重新渲染该话题
  → 信息面板刷新
```

## 9. 验收标准

- 按 `V` 能从轨道切换到第一人称
- WASD 移动不穿墙
- 鼠标控制视角流畅
- 准心对准物体显示名称提示
- 点击物体打开信息面板
- 信息面板显示相关话题、当前选项、替代方案
- 在信息面板切换方案，3D 场景同步更新
- 总览菜单能显示当前方案、决策记录；预算/风险/归档区域可留占位
