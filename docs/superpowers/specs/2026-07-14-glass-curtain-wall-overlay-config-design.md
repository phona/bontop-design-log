# 玻璃幕墙 Overlay 配置校准

- 日期：2026-07-14
- 状态：已确认（待实施）
- 前置：`2026-07-14-dxf-overlay-rendering-design.md`（本 spec 是该架构在幕墙配置层的具体落地）

## 背景与问题

当前 `config/layout/overlay.yaml` 的 `glass_facade` 定义存在两个问题：

1. **形状过度简化**：使用 4 点矩形 + 0.8m 圆角近似，丢失了 DXF 提取出的 S 拐角和 SW/NW 斜面过渡。导致幕墙与 DXF 外墙线、户型图效果图均对不齐。
2. **`suppress` 为空**：按设计流程，`suppress` 应在视觉验收后按反馈补入。当前为空占位符，导致被幕墙替换的外部墙体仍被渲染为实墙。

## 设计决策

将 `glass_facade` 从 4 点简化版改为 **7 点折线**，精确匹配 DXF 提取出的外墙几何：

- 补回 S 拐角（南外墙西端）
- 补回 SW 斜面（南墙向西墙的过渡）
- 补回 NW 斜面（西墙向北墙的过渡）
- 西段端点使用实际外墙端点（`z=-2.99` 和 `z=4.872`），而非理论交点

同时添加 5 个 `suppress` 区域，精确覆盖被幕墙替换的外部墙段。

## 7 点折线坐标

```yaml
- id: glass_facade
  type: curtain_run
  points:
    - {x: 3.745, z: -4.323}       # 南段东端
    - {x: -0.578, z: -4.323}      # S 拐角
    - {x: -5.75, z: -3.17}        # SW 斜面
    - {x: -5.88, z: -2.99}        # 西段南端
    - {x: -5.88, z: 4.872}        # 西段北端
    - {x: -5.363, z: 5.39}        # NW 斜面
    - {x: 3.745, z: 5.39}         # 北段东端
  height: 3.0
```

### 坐标来源与理由

| 点 | 坐标 | 来源 | 说明 |
|---|---|---|---|
| P1 | `(3.745, -4.323)` | DXF 南外墙东端 | 主户型南立面最东端，与入户花园西边界相邻 |
| P2 | `(-0.578, -4.323)` | DXF 南外墙西端 | 南外墙从 P1 到 P2 是直线段，P2 是 SW 过渡的起点 |
| P3 | `(-5.75, -3.17)` | DXF SW 斜面近似 | 连接 P2 到 P4 的过渡点，近似 SW 圆角 |
| P4 | `(-5.88, -2.99)` | DXF 西外墙南端 | 西外墙的实际起点 |
| P5 | `(-5.88, 4.872)` | DXF 西外墙北端 | 西外墙的实际终点 |
| P6 | `(-5.363, 5.39)` | DXF NW 斜面起点 | 西墙向北墙的过渡起点 |
| P7 | `(3.745, 5.39)` | DXF 北外墙东端 | 主户型北立面最东端，与入户花园西边界相邻 |

### 入户花园边界

`x=3.745` 是主户型与入户花园的分界线。入户花园的西边界（`x>3.745` 的竖向墙段）是**实墙**，不是玻璃幕墙。因此：

- 幕墙的南段东端（P1）和北段东端（P7）都止于 `x=3.745`
- `suppress` 区域不覆盖 `x>3.745` 的墙体
- 入户花园的南、北、东边界保持为实墙

## Suppress 区域

```yaml
suppress:
  - id: suppress_south_wall
    region: {x1: -0.7, z1: -4.5, x2: 3.9, z2: -4.1}
    reason: "南外墙改玻璃幕墙"
  - id: suppress_sw_corner
    region: {x1: -6.0, z1: -3.5, x2: -5.0, z2: -2.9}
    reason: "SW 圆角改玻璃幕墙"
  - id: suppress_west_wall
    region: {x1: -6.0, z1: -3.0, x2: -5.7, z2: 4.9}
    reason: "西外墙改玻璃幕墙"
  - id: suppress_nw_corner
    region: {x1: -6.0, z1: 4.8, x2: -5.0, z2: 5.5}
    reason: "NW 圆角改玻璃幕墙"
  - id: suppress_north_wall
    region: {x1: -5.5, z1: 5.2, x2: 3.9, z2: 5.5}
    reason: "北外墙改玻璃幕墙（入户花园以西）"
```

### Suppress 区域设计原则

1. **精确覆盖**：每个区域只覆盖对应 DXF 墙段的中点，不误伤相邻墙段
2. **不碰入户花园**：北墙区域 `x` 范围 `[-5.5, 3.9]`，不覆盖 `x>3.745` 的入户花园西墙
3. **区域独立**：5 个区域分别对应南墙、SW 角、西墙、NW 角、北墙，便于单独调试

## 与旧方案的对比

| 项目 | 旧方案（4 点） | 新方案（7 点） |
|---|---|---|
| 南段 | `x: 3.75` 到 `x: -5.88` | `x: 3.745` 到 `x: -0.578`（补回 S 拐角） |
| 西段 | `z: -4.32` 到 `z: 5.39` | `z: -2.99` 到 `z: 4.872`（实际外墙端点） |
| 北段 | `x: -5.88` 到 `x: 3.75` | `x: -5.363` 到 `x: 3.745`（补回 NW 斜面） |
| 西南角 | `radius: 0.8` 圆角 | 显式 SW 斜面点 `(-5.75, -3.17)` |
| 西北角 | `radius: 0.8` 圆角 | 显式 NW 斜面点 `(-5.363, 5.39)` |
| suppress | `[]` 空 | 5 个区域精确覆盖 |

## 验证步骤

1. **单元测试**：`npm run test:server` 确保 overlay-merge 解析通过
2. **视觉验收**：
   - 启动 dev server：`npm run dev:server & npm run dev:app`
   - 核对南、西、北立面为半透明玻璃幕墙
   - 核对入户花园西墙为实墙
   - 核对 SW/NW 斜面过渡平滑
   - 核对幕墙与 DXF 外墙线接缝对齐
3. **回归测试**：`python3 -m pytest scripts/parse_cad_test.py -q` 确保坐标提取无误
