# 收纳三层方案设计（主卧深柜段 + NW 次卧置物架墙 + 床箱床选型）

日期：2026-08-12
状态：已实施（2026-08-12，见文末校订）
触发：业主确认现住房"一间儿童房退化成仓库"（被褥/书籍/杂物下意识堆积）——低频大件收纳需求由假设变为实证；DEC-010/013 已否决榻榻米，需给出符合防尘、弹性、低摩擦三原则的替代方案

## 背景与问题

两人住四房，西北次卧（儿童房 8.39㎡）在孩子出生前无日常使用人，是父母房（需保持可接待）之外唯一可退化的房间。设计响应不是对抗"下意识堆放"，而是**给低频物品修一条比地板阻力更小的路**：

- 低摩擦原则：开架+统一收纳箱 > 柜门 > 抽屉 > 榻榻米掀盖（已否决，回南天密闭贴地箱体养霉）
- 指定唯一出口：NW 次卧合法承担仓储，保住其余空间
- 弹性可恢复：全部用成品/可清场家具，复刻 DEC-013 父母房弹性逻辑

## 目标 / 非目标

**目标**：
- 三层收纳落地：低频（被褥/行李箱）→ 主卧深柜段；极低频（书/杂物）→ NW 次卧置物架墙；季节层 → 床箱床
- 3D 可体验：深柜段与置物架摆位渲染 + clearance 规则自动校验 + 第一人称动线走查

**非目标**：
- 榻榻米（已否决）；开放格嵌灯带（撞 DEC-013 防尘策略）
- 不动 model-geometry.yaml / overlay.yaml / 电气 / 衣柜推拉门决策
- 床箱床不进 3D（外观与现有床体块无差异，属采购规格）

## 变更清单

### 1. shared/types.ts — FURNITURE_DIMS 注册三个新类型

```ts
wardrobe_120:      { width: 1.2, depth: 0.6 },
wardrobe_120_deep: { width: 1.2, depth: 0.8 },
shelf:             { width: 0.8, depth: 0.4 },
```

### 2. app/src/render/FixtureFactory.ts — 三个新配方

- `wardrobe_120`：复刻 wardrobe_180 单体块（1.2×2.7×0.6，同色 #8B7355）
- `wardrobe_120_deep`：同上进深 0.8
- `shelf`：置物架——两侧立板 + 4 层横板（总高 2.0m），比满背衣柜体块更显"开架"，色 #8B7355

无碰撞改动（家具本就不进 extractCollisionWalls，AGENTS.md 铁律不涉及）。

### 3. config/house.yaml — furnishings 摆位

**主卧**：wardrobe_240（@3.00,5.85 rot0，占 x∈[1.8,4.2] z∈[5.55,6.15]）拆为两段：
```yaml
- { type: wardrobe_120_deep, x: 2.40, z: 5.95, rotation: 0 }   # 西段加深 0.8m，向南占 z∈[5.55,6.35]
- { type: wardrobe_120,      x: 3.60, z: 5.85, rotation: 0 }   # 东段维持 0.6m，靠门侧不动
```
- 入口动线走衣柜背面北侧（z≈5.1–5.55），**零侵占**
- 预计算：深段南缘 z=6.35 vs 床北缘 z≈6.975，通道 ≈0.63m > 0.50 规则下限；verify 复核
- count 口径：wardrobe_240 count 由列表 derive（AGENTS.md 禁双写）——需在注释说明 240 拆 120+120_deep，预算按同投影面积等价（深度增加 0.2m 计 +0.5~1k，见 §5）

**西北次卧**：北墙西段加置物架（上飘窗 sill=2.55m 在头顶，窗下墙面空置）：
```yaml
- { type: shelf, x: 3.05, z: 1.30, rotation: 0 }   # x∈[2.65,3.45] z∈[1.10,1.50]
```
- 预计算：与 wardrobe_180（z 起于 1.8）净距 0.3m；与床（x 起于 3.85）净距 0.4m；不与门摆（x∈[4.55,5.45]）相交
- **风险**：北墙 1.5m 窗的准确位置 inferred——若窗偏西压住 x∈[2.65,3.45]，备选方案：shelf 缩 0.6m 宽 / 改北墙东段。以 3D + 量房裁定
- NW 次卧定位注释更新："儿童房（前孩时代 = 储物+客房，成品家具可清场）"

### 4. config/materials.yaml — 选型注记（无价格变动）

## 决策记录要求

实施后落 DEC-023，要点：
- NW 次卧定位："儿童房（前孩时代 = 储物+客房，弹性恢复）"——正式替代"退化仓库"的默认结局
- 三层收纳方案与低摩擦原则（开架 > 柜门 > 抽屉 > 掀盖）
- 榻榻米否决归档（回南天密闭箱体 + 高摩擦 + 焊死弹性，三条独立成立）
- 衣柜报价矛盾列为门店核价头号项

## 风险与边界

1. NW 北墙窗位 inferred——置物架最终墙面待量房/3D 裁定，spec 已列备选
2. 深柜段 +0.2m 深度超出 FURNITURE_DIMS 标准衣柜语义，预算按投影等价处理并注释，避免 per-size 计价（DEC-012 遗留）介入前的口径混乱
3. 本方案与 PBR spec（2026-08-12-pbr-floor-rendering-design.md）独立，可任意顺序实施；若 PBR 先落地，走查体验更佳但非前置条件

## 实施校订（2026-08-12）

- §1/§2 双类型方案改为**单类型 `wardrobe_240_split`**（一个体块配方内含深段+标准段两个盒子）：count 模式下每个映射 wardrobe topic 的类型都会按默认价计 1 组，双类型会导致 1 组衣柜计 2 次价（4200→8400 虚增）。单类型保 count=1 预算口径，FURNITURE_DIMS footprint 取最深 0.8 保 clearance 真实性
- §4 shelf_01 候选**未建独立 topic**：新 topic 牵涉 TopicRegistry/topicMap/count 配置链，按 DEC-018 先例（书桌椅 +1500 手动调池）由 furniture_soft 池备注消化，DEC-023 已记 +1~2k 估算
- §3 置物架摆位 (3.05,1.30) → (3.00,1.30)：初摆触发 clearance 0.05m 警告（规则 flush 阈值 <0.05），改为贴西北转角，警告消除且不占过道
- 床箱床/衣柜核价注记已落 materials.yaml（bed_180_01 指令、新增 bed_150_01、wardrobe_240_01 红旗）
