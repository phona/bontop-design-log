## 二、可视化增强（Phase 1）

### 架构

HouseScene.ts 瘦身，按功能拆出独立 Manager：

```
app/src/render/
├── HouseScene.ts          ← 编排逻辑，调用 Manager 接口
├── TextureManager.ts      ← NEW: 纹理加载/缓存/应用
├── EnvironmentManager.ts  ← NEW: 程序化环境光/IBL/阴影
├── AnalysisTools.ts       ← NEW: 测量/透墙/碰撞高亮
├── TextureFactory.ts      ← 保留(退化 fallback)
├── FurnitureFactory.ts    ← 不变
└── ObjectFactory.ts       ← 不变
```

### TextureManager

- **方案：** 增强现有程序化纹理（零外部素材依赖）
  - 木纹：年轮/节疤模拟，支持不同树种（橡木、胡桃、樱桃）
  - 瓷砖：多种拼法（工字、人字、六角），可配置规格
  - 涂料：哑光/蛋壳光/肌理漆质感
  - 石材（新增）：仿大理石纹、水磨石颗粒
  - 程序化生成法线贴图，让材质有立体感
- 方案纹理（scheme textures）通过 `applySchemeTextures()` 应用
- 加载失败降级到现有 `TextureFactory`，不中断渲染

### EnvironmentManager

- 程序化天空球 + IBL（PMREMGenerator，梯度环境贴图）
  - 玻璃/金属自动反射天空颜色
  - 不依赖外部 HDR 文件
- 阴影升级：PCF → PCFSoftShadowMap，加 bias 调优
- 主光源角度对应实际太阳位置（东南→西南）
  - 可直观评估「下午西晒」等效果
- **不做：** 动态时间动画、多光源、后处理(Bloom/SSAO)

### AnalysisTools

三个工具，统一在 `AnalysisTools.ts` 中：

**1. 激光测量**
- 俯视图：鼠标悬停显示坐标，点击打点测量距离
- 第一人称：调出工具 → 准星定位 → 打点
- 结果显示 `长度 + 分轴(X/Z) 分量`
- 测量结果可清除、可存档

**2. 透墙模式**
- 快捷键 `W` 切换，非承重墙透明度 0.15
- 结构柱/剪力墙保持不透明（以 model-geometry.yaml 的 wall type 区分）
- 俯视图自动进入透墙模式

**3. 碰撞高亮**
- 家具超边界 → 红色 emissive 脉冲闪烁
- 测量线穿透墙体 → 穿墙段变红
- 结合现有 CollisionDetector 做可视化反馈

## 三、施工文档（Phase 3）

### 总则

所有图纸以浏览器 SVG 标签图呈现，后续可扩展 PDF 导出。新配置数据（插座、给排水、天花）写入 `config/` 下新 YAML 文件。

### 3.1 插座开关点位

**通用原则：**
- 每房间至少 2 面墙有插座，防家具遮挡
- 床头双控开关
- 厨房台面插座带独立开关
- 卫生间带防溅盒
- 儿童房插座离地 1.2m，其余 0.3m
- 每房间预留网口（Mesh 有线回程）

**客厅：**
| 位置 | 数量 | 说明 |
|------|------|------|
| 电视墙（西墙 x=7.20，即西南次卧东墙） | 4+网口 | 电视+音响+机顶盒+预留，USB×2 |
| 沙发两侧（朝东） | 各2个 | 手机充电+落地灯 |
| 饮水机位（东南角） | 1个 | 近水源 |
| 餐桌旁 | 1+地插 | 火锅/电磁炉 |
| 窗帘侧（南幕墙） | 1个 | 电动窗帘预留 |
| 空调/新风内机 | 1个 | 吊顶内 |

**灯光控制：**
- 客厅双控：入户门侧 + 主卧走廊入口侧
- 电视墙暗埋 50mm 穿线管走电视线

### 3.2 给排水走向

**热水方案：** 零冷水燃气热水器（预埋回水管），主卫/客卫/厨房三个用水点循环。

**用水点：**
| 区域 | 给水 | 排水 |
|------|------|------|
| 主卫 | 洗手台+淋浴+马桶 | 全部 |
| 客卫 | 洗手台+淋浴+马桶 | 全部 |
| 厨房 | 洗菜盆 | 台盆下水 |
| 厨房净水 | 台下净水器（预留插座+柜体空间） | — |
| 生活阳台 | 洗衣机+拖把池 | 地漏 |
| 入户花园 | 水龙头+地漏（浇花、洗拖把） | 地漏 |

**马桶：** 普通马桶（不搞壁挂）。

### 3.3 天花吊顶

| 区域 | 做法 | 理由 |
|------|------|------|
| 客厅 | 局部吊顶（走管区 25~30cm） | 藏中央空调内机/管线 |
| 走廊 | 吊平 | 与客厅衔接 |
| 厨房 | 集成吊顶（铝扣板） | 检修油烟/新风管 |
| 主卫+客卫 | 集成吊顶 | 检修排气管 |
| 主卧+西南次卧+儿童房+书房 | 周边石膏线 | 不吊顶 |
| 入户花园 | 防水涂料 | 不吊顶 |

### 3.4 隐藏式晾衣架（客厅南幕墙）

**做法：**
- 嵌入客厅南侧吊顶内
- 预埋加固板（细木工板或金属龙骨）承重
- 预留零火地三线电源
- 晾衣架在幕墙内侧，非外侧

**推荐产品：** 晾霸 Q3/Q5、邦先生 M33、好太太 D-3138（超薄，收合厚度 <10cm）

**与烘干机配合：**
- 晴好天气 → 客厅隐形晾衣架（南向直射）
- 阴雨天 → 生活阳台热泵烘干机
- 全年无死角

### 3.5 空调方案

**选型：** 美的理想家 III 一拖五（A2 方案）
- 外机放西平台（VRV 设备平台）
- 内机：客厅+主卧+西南次卧+书房+儿童房，各一台天花内机
- 预算 2.8~3.0 万
