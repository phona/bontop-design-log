# HVAC 方案深化（2026-09-07）

> **背景**：业主指出此前空调选品（美的理想家 III 6HP 等）为 AI 占位生成，未经真实研究，要求做**方案级深化**。
> 本文以真实市场调研 + 负荷计算重做选型逻辑。配置权威源：`config/hvac.yaml`（A2 `load_design`）。
> **状态**：方案级（proposed）。品牌未定标；定标后由厂商做样册级选型与冷负荷软件复核。
> **关联**：DEC-2026-09-07-055；`config/ceiling.yaml`（内机容量标注同步）；`docs/hvac_options_analysis.md`（系统级方案对比，仍有效）。

## 一、深化的三个事实纠正

| # | 原占位方案的问题 | 深化后的结论 |
|---|------------------|--------------|
| 1 | 外机 6HP（≈15.5kW） vs 内机标称合计 13.4HP（≈33.5kW），连接率≈223%，远超行业上限 | 内机大幅**下调**至按房间负荷选型（合计 21.4kW）；外机**上调**至 7HP 级（≈18kW），连接率 ≈1.19，落在行业上限 120–130% 内 |
| 2 | 客厅内机标 "4HP(≈10kW)" 看似偏大，实际是对的：45.88㎡ 客餐厅 + 8.64㎡ 开放厨房 ≈ 54.5㎡，行业口径 45–50㎡+开放厨房需 **9–11kW**（≈200–220W/㎡） | 客厅内机维持 **10.0kW（5HP 级）**，为全系统最大内机 |
| 3 | 卧室内机 2.2HP（≈5.6kW）用于 8–13㎡ 房间，超配 2–3 倍；主卧 2.8HP（≈7.1kW）用于 17.9㎡ 同样偏大 | 主卧降为 **4.5kW**、父母房 **2.5kW**、儿童房/书房各 **2.2kW**——风管机体积随之变小，吊顶/门头盒包络全部松一格 |

**连接率依据**：各品牌允许最大超配率基本在 120%–130%；全屋经常同开建议 ≤110%，分时分区可接近 120%–130%（来源见文末）。本户两人常住、白天客厅/夜间卧室的分时使用模式，≈1.19 合理。

## 二、系统架构：为什么仍必须是多联机（论证保留）

全屋唯一外机位为**西设备平台 1.6m×1.55m≈2.48㎡**（701 专属，入户花园含消防通道不可用、南阳台不做设备区、幕墙外挂被禁止）：

- 多台分体外机并排（2 台 ≈1.8m）已超平台净宽 1.6m → B/C/D/E 系（分体组合）在平台布置上不可行（详见 hvac_options_analysis.md 三）。
- "客厅一拖一风管机 + 卧室多联机"混合方案需要 **2 台外机**，平台放不下 → 出局。
- **单台多联机（一拖五）是唯一满足约束的架构**——此结论与原方案一致，维持。

## 三、房间负荷与内机选型（方案级）

内机容量档位（10.0/4.5/2.5/2.2）为主流薄型风管机标称序列，**具体以定标品牌样册为准**（各品牌档位命名略有差异）。

## 四、外机容量推导

- 6HP（≈15.5kW）：21.4 ÷ 15.5 = **138% → 超上限，出局**。这一条直接否决"小米 6匹一拖五 ≈1.6 万"等低价方案的照搬可能（除非把客厅内机压到 8kW 牺牲负荷余量，不建议）。
- **7HP（≈17.5–18kW）：连接率 ≈1.19 ✓ 主推**。家用机主流上限即 7HP（如美的酷省电Pro 7匹一拖五、格力 7 匹档），供应链成熟。
- 8HP（≈20kW）：连接率 ≈1.07，同开冗余最好，但家用线少见于主流品牌（多为工程线），**作为备选项**：若定标经销商确有 8HP 家用机型且预算可 +3k–5k，可升级。
- 校验：夜间四卧同开 2.2+2.2+2.5+4.5=**11.4kW < 18kW**，不超载；白天客厅单独运行 10kW < 18kW，压缩机处于中高负荷区效率好。

## 六、预算影响

- 现预算 `hvac` 科 = 29,000（base.json），按 A 档 7HP 实际成交价 ≈ **差额 0 ~ +7k**。
- 未动预算：按项目治理，科目调整需业主拍板后再改 `config/budget/base.json`。预留路径：若最终 ≤2.9 万则无影响；若超，优先从 `appliances`（家电分阶段采购）缓手。
- 询价时的行业坑（沿用 hvac_options_analysis.md 五）：低价裸机、铜管只送 7–8m/台、风口加长、冷凝水提升泵、串货机——报价单要求逐项列明。

## 七、与电气/吊顶的联动（已具备）

- 5 路空调专用回路（`hvac_power_*`）已在 `config/electrical-topology.yaml` 声明，内机下调后每路负荷 ≤0.2kW，1.5mm² + C16 足够（拓扑参数 2026-09-07 已补 proposed 值）。
- 主卧门头盒 `ceiling_master_ac`、各房边吊为原 2.2–2.8HP 内机设计，内机全部下调后**净空只松不紧**，无需改吊顶几何。
- 冷凝水路线（`condensate_*_candidate`）不变，仍受"绕梁优先、不得假定接现有地漏"约束。

## 八、遗留与待办

1. **业主拍板**：品牌档位（A–E）与是否加预算上 8HP；
2. 定标后：厂商样册级选型 + 冷负荷软件复核 + 出配置单（含连接率声明）；
3. 量房时复核：西平台实际净尺寸/百叶有效通风面（pending #14）、外机吊装路径；
4. 内机回风口滤网可拆洗性在吊顶深化图上标注（开放厨房油烟）。
