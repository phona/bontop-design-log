# 验收清单

## 通用验收原则

- 每一道工序未经业主验收，不得进行下一道工序。
- 验收时必须拍照/录像，归档到 `survey/photos/` 和 `survey/videos/`。
- 不合格项必须整改并复验，记录在 `audit/audit.log`。

## 一、拆除与新建墙体

- [ ] 拆除位置与图纸一致
- [ ] 新建墙体垂直度、平整度合格
- [ ] 门头过梁规范
- [ ] 垃圾清运完毕

## 二、水电改造

- [ ] 水管打压 0.8MPa，30分钟不掉压
- [ ] 电路通电测试正常
- [ ] 强弱电间距 ≥50cm
- [ ] 插座、开关位置与图纸一致
- [ ] 水电走向拍照/录像归档

## 三、防水工程

- [ ] 卫生间防水高度：淋浴区 ≥1.8m，其他 ≥0.3m
- [ ] 厨房、阳台防水完成
- [ ] 闭水试验 48小时无渗漏

## 四、泥瓦工程

- [ ] 瓷砖空鼓率 <5%
- [ ] 阴阳角方正
- [ ] 地面排水坡度正确
- [ ] 勾缝/美缝完整

## 五、木工工程

- [ ] 吊顶龙骨牢固
- [ ] 吊顶平整度合格
- [ ] 窗帘盒、空调出风口预留正确

## 六、油漆工程

- [ ] 墙面平整、无裂缝
- [ ] 乳胶漆涂刷均匀
- [ ] 颜色与样板一致

## 七、安装工程

- [ ] 门窗开关顺畅、密封良好
- [ ] 卫浴五金安装牢固
- [ ] 橱柜平整、门板缝隙一致
- [ ] 灯具、开关、插座全部可用

## 八、竣工验收

- [ ] 全屋保洁完成
- [ ] 空气质量检测合格（甲醛、TVOC）
- [ ] 质保单交付
- [ ] 钥匙、门禁卡移交
- [ ] 尾款支付前所有问题已解决
