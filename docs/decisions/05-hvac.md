### DEC-2026-09-07-055 空调方案深化：内机按负荷重选 + 外机定 7HP 级（品牌未定标）

- **日期**：2026-09-07
- **起因**：业主澄清原选品（美的理想家 III 6HP 等）为 AI 占位、未经真实研究，要求方案级深化。
- **决策事项**：
  - **内机重选**（合计 21.4kW）：客餐厅+开放厨房 54.5㎡ → 10.0kW（5HP 级，行业口径 45-50㎡+开放厨房需 9-11kW）；主卧 7.1→4.5kW；父母房 5.6→2.5kW；儿童房 5.6→2.2kW；书房 5.6→2.2kW。

  - **品牌未定标**：短名单 A 美的 7匹（2.8-3.4万，主推）/ B 格力（3.2-3.8万）/ C 小米 6匹（连接率不合规，须内机 ≤20kW 配置单才可救活）/ D 大金日立（超预算不推荐）/ E 海尔（居中）。见 `docs/hvac-deepening-20260907.md`。

- **关联文件**：`config/hvac.yaml`（A2 outdoor + load_design）、`config/ceiling.yaml`（五台内机容量标注）、`config/house.yaml`（hvac 段与 pending_verification）、`config/tradeoffs.yaml`（hvac_brand 短名单）、`docs/hvac-deepening-20260907.md`（新增）、`docs/hvac_options_analysis.md`（头部口径更新）

### DEC-2026-10-03-R6 中央空调配置定版：200W 外机 + 21.6kW 六内机（supersedes DEC-2026-10-03-R5）

- **日期**：2026-10-03
- **编号说明**：原稿误用 R2（已被同日"业主全硬装询价轮次归档"占用），本 HVAC 决策改号 R6；R2/R3/R4/R5 均保留为历史事件
- **supersedes**：DEC-2026-10-03-R5（空调逐台容量表：客餐厅拆两台、第 6 台落客餐厅，25.6kW/1.28）
- **起因**：业主先后提供美的内机参数表、同小区参考报价（邦泰璟和 110 户型，2026-04-27）、4.4 万高配报价三份材料；原 DEC-2026-09-07-055 的 5 台 21.4kW/18kW 外机（连接率 1.19）无法覆盖餐厅冷量盲区，而销售新版 71+45+56+28×3=25.6kW 在 18kW 外机上连接率 1.42 超限。
- **选定方案**：
  1. **外机领航者Ⅳ MJV-200W-E01-LHIV（20kW）**；内机 71T2（客厅）+28T2（餐厅，新增）+45T2（主卧）+28T2（父母房）+22T2（儿童房）+22T2（书房）= **21.6kW，连接率 1.08**。
  2. 餐厅机位定在既有北缘边吊西端 (8.00,4.75)，同向侧送朝南，服务餐桌区；要求风口避开座位正上方。
  3. 主卧 45T2 必须带冷凝提升泵（门头盒绕行无法保证连续 1% 重力坡）；儿童房/书房维持 22 级（北向玻璃无直射 / 面积小），不为"留裕度"升档。
  4. 明确不计入：厨房空调（用开门借餐厅冷气 + 循环扇）、新风（另案）。
- **决策依据**：
  - 负荷口径：各房间同时峰值约 17kW；外机额定→高温降额（38–40℃ 约 −8~12%）→长配管降额（最远内机约 15m 正交 + 2.5m 高差）三层叠加后，18kW 净值约 15.5kW（不足）、20kW 约 16.5–17kW（覆盖）、22.4kW 约 18.5kW（富余）。
  - **外机大小主要买"同时满载总量余量"；单间能力上限由该内机额定值决定，但更大外机会改善多房同时运行能力与部分工况效率**；故不为 22.4kW 多付约 3,500，转投主卧电动西窗帘（砍 0.6–0.9kW 太阳得热，每日兑现）。
  - 交叉验证：同小区参考方案客餐厅 55㎡ 配 80 级=145W/㎡，本方案客厅 45.88㎡ 配 71 级=155W/㎡，口径同级，未超配（45.88㎡ 为客餐厅 bbox 含 1.3㎡ 凹口，仅作保守交叉验证；实际 44.58㎡，客厅区 31㎡+餐区 14㎡ 分区口径见下）。
  - 厂家参数表实测：22/28/36 机身同为 700×450×200mm，故儿童房/书房选 22 级无安装差异；22T2 低风噪音 17dB(A) 优于 28T2 的 19dB(A)。
  - **面积口径修正**：客餐厅（living_dining）**实际 44.58㎡**（polygon 实测；bbox 45.88㎡ 含 1.3㎡ 凹口）。此前 RFQ 写"客厅 45.88㎡"又另列"餐区 14㎡"属重复计量。正确口径：按气流覆盖拆两个热区——客厅区约 31㎡→71 级（229 W/㎡）、餐区约 14㎡→28 级（200 W/㎡），合计 9.9kW÷44.58㎡≈**222 W/㎡**。同小区参考方案为"负荷估 230 W/㎡、设备选 145 W/㎡"，我们取负荷口径，须经销商冷负荷计算书背书。
  - **降额链修正**：原"38–40℃ 降额 8~12% + 长配管降额 + 18kW→15.5 / 20kW→16.5–17 / 22.4→18.5"为方案级估算，无厂家修正曲线作证，不得写成设备确定性能。按经销商报价单给出的南宁设计参数（夏季室外干球 34.2℃、湿球 27.5℃）重估：18kW 外机净值约 16.5–17.5kW、20kW 约 18–18.5kW。20kW 结论不变，但差距比原估算窄。
  - **单位与归因修正**：西晒窗帘降低的是峰值得热约 0.6–0.9kW，按西晒时段约 3.5h 折合约 **2 kWh/天**（kW 是瞬时值、kWh 是能量）；起作用的是"窗帘关闭"，不是"电动"本身。
  - **外机平台硬门槛**：西设备平台 1.6×1.55m 处于玻璃幕墙体系。除能否塞下外机外，还须书面核算百叶有效通风面积、进排风净距、检修距离与热短路风险（参照美的领航者三代 180W 外机约 951×383×1333mm，200W 级更大）。"放得进去"不等于"夏天能正常排热"。
  - **状态拆分**：owner_selected（2026-10-03 业主定标配置）/ vendor_verification_pending（第二家分项报价、厂家冷负荷计算书、外机平台散热核算、厂家正式配电图、外机供电制式）/ construction_not_frozen（量房与水电交底前不施工冻结）
- **现场待确认**：① 外机位 1.6×1.55m 能否容纳 200W 外机及其供电制式（220V/380V）；② 分项报价与风口加长、超长铜管计价；③ 主卧台盆/龙头、马桶 SKU 未定，相关给排水与插座维持 site_pending。
- **current state 回写**：本决策已同步编译回 config/hvac.yaml（6 台 21.6kW / 20kW / 1.08）、config/ceiling.yaml（ac_dining @(8.00,4.75)）、config/electrical.yaml（sock_dining_ac）、config/electrical-topology.yaml（hvac_power_living 增成员、容量 ≤0.6kW）、config/mep-hvac-coordination.yaml（餐厅冷媒/冷凝水/送回风）、docs/pending-site-data.md #39、schedule/procurement.md §01，消除"同一问题多个当前答案"
- **关联文件**：`docs/hvac-rfq-brief-20261003.md`（询价需求书，交第二家经销商）、`config/hvac.yaml`（本轮已回写，见 current state 回写）、同小区参考报价（.xlsx，业主提供）、`docs/pending-site-data.md` #39
- **决策人**：业主（选配置与预算口径）；施工尺寸待量房与厂家冷负荷软件复核
