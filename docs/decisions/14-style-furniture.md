### DEC-2026-08-20-024 地板定案：全屋人字拼（浅暖橡木），深色家具承担沉稳感

- **日期**：2026-08-20
- **决策事项**：客餐厅+卧室地面铺法与色调定案（解开 2026-08-12 待决策 #5 的 3D 关）
- **可选方案**：
  1. 800×800 木纹砖方格平铺（原案 floor_tile_01）
  2. 600×1200 木纹砖步步高错缝 + 近色美缝
  3. 人字拼（本方案）
- **选定方案**：**全屋人字拼，浅暖橡木色（渲染 tint #c49a6c）**；深色餐桌椅/皮沙发等"可换前景"承担沉稳感，地板保持百搭浅色
- **决策依据**：
  - 3D 关通过：Blender PBR 管线重渲（herringbone_parquet 真扫描 + daylight 工况），人字拼在客厅四机位下明显优于 800 方格与 612 错缝（渲染代理上限已验明：单贴图+双色混铺无法模拟真砖 6+ 版面）
  - 百搭/过时分析：浅橡木=北欧/日式几十年常青底色，家具可换风格；深棕地板风格锁定且显灰尘水印
  - 价值工程（业主"特斯拉思路"）：装饰费只花在地面这个最大视觉面，石膏线/墙面线框等纯装饰不投入
  - 参考实证：业主提供 3 套实景照片（混铺木纹砖/人字拼深色版/人字拼浅版+深家具撞色），共同特征=人字拼+深浅混铺+柔光
- **预算影响**：+6~10k（DEC-023 预估口径，含工费差+损耗差），190k ceiling 内；降级预案=612 错缝木纹砖（已建模 floor_pbr_tile_612）
- **执行/采购纪律**：木纹砖人字拼条板门店四问——版面数 ≥6、柔光/天鹅绒釉（回南天拒深模具釉）、工费与损耗报价、新砖除蜡要求；美缝环氧彩砂调同色
- **关联文件**：`data/current-scheme.json`（floor/bedroom_floor=floor_pbr_herringbone）、`config/materials.yaml`（floor_pbr_herringbone / floor_pbr_tile_612 / floor_pbr_veneer_matched）、`renders/floor-compare/`（A/B 留档）、`renders/blender/output/`（daylight 巡览）
- **决策人**：业主

### DEC-2026-08-20-025 家具风格定调中古胡桃 + Blender 渲染真实感升级

- **日期**：2026-08-20
- **决策事项**：①软装风格定调；②Blender 渲染资产/光照升级（业主提供中古风实景参考图后）
- **可选方案**：
  1. 法式奶油（2026-08-14 spec 原方向：白漆木家具+羊羔绒浅色软装）
  2. 中古胡桃（本方案：黑皮沙发+深胡桃木家具+浅地板撞色）
- **选定方案**：**中古胡桃**。硬装/定制柜维持浅色百搭（PET 肤感柜门不动），深色由可换成品家具承担——与 DEC-024"地板锁定浅色、风格交给家具"一致
- **决策依据**：
  - 耐看度：深浅撞色结构（浅地板+深家具+白墙）层次有锚点；胡桃/皮革越用越有光泽；奶油风全网同质化、浅色软装显新期短
  - 灵活性：家具可换，十年后换风格不动硬装；定制柜深色化=风格锁定，明确不做
  - 渲染升级（提升决策参考性）：家具 GLB 化（Poly Haven CC0：sofa_02 黑皮沙发 / dining_chair_02 深棕皮餐椅 / WoodenTable_01 餐桌 / modern_wooden_cabinet 深胡桃格栅电视柜）；地板渲染参数校到柔光浅橡木（tint #d4b48a、coat 0.3→0.1、roughness 0.55 覆盖，对齐 DEC-024 门店四问的柔光釉要求）；daylight 工况挂真 HDR 外景（kloofendal_48d）+ 西南向午后太阳直射、不开灯
  - 路线取舍：走 Blender 资产升级（可控可复现、A/B 可信），不走 img2img AI 静帧（无工具链、细节易失真）
- **预算影响**：无新增（家具采购池内选深色款；灯光升级仍为待决策 #4）
- **关联文件**：`assets/furniture/`（5 套 CC0 GLB）、`hdri/kloofendal_48d_partly_cloudy_1k.hdr`、`assets/SOURCES.md`、`scripts/blender/dress_scene.py`（FURNITURE_GLB）、`scripts/blender/gen-render-config.ts`（daylight 工况）、`config/materials.yaml`（floor_pbr_herringbone）、`docs/dressing-map.md`
- **决策人**：业主

### DEC-2026-08-20-026 中古款式细化：直排沙发/细腿餐椅/深胡桃餐桌/圆几 + 采购清单对齐

- **日期**：2026-08-20
- **决策事项**：设计审查第 1 轮后的款式拍板（沙发/餐椅/餐桌/茶几四件 + 材质立场 + 采购清单重刷）
- **可选方案**：见 DEC-025 审查（Chesterfield 拉扣 vs 直排现代；高背拉扣椅 vs 细腿软包椅；工业方几 vs 圆几；岩板餐桌 vs 深胡桃木桌；全屋真皮 vs 仿皮）
- **选定方案**（业主逐条拍板）：
  1. **沙发**：直排、简洁、低矮现代中古款（深棕/黑棕），轮廓克制、体量轻——**否决 Chesterfield 弧形拉扣**
  2. **餐椅**：细腿软包椅（深棕皮/仿皮），无拉扣、降高背——**否决高背厚重款**
  3. **餐桌**：深胡桃/深棕木质视觉，造型简洁，不要求实木——**取消岩板+碳素钢腿**
  4. **茶几**：圆形/椭圆，黑色/深木色，轻巧——**取消工业风方几与岩板茶几**
  5. **深色餐边柜/斗柜**：暂不新增；先改对四大件再看画面平衡，确有收纳需求且视觉仍飘再议
  6. **材质立场**：不强制全屋真皮；款式/比例/木色/腿型/表面质感优先，沙发保触感、餐椅可用好仿皮
  7. **基础体系不动**：浅人字拼+暖白墙+浅定制柜为背景，深色只做可换家具与视觉锚点
- **决策依据**：设计审查结论——采购清单（dressing-map/materials.yaml）残留"科技布沙发/岩板餐桌"等现代简约项，与 DEC-025 定调脱节，落地必买错；款式分歧（拉扣 vs 直排等）直接决定风格走向
- **预算影响**：沙发 3200→4200（仿皮中古款）、餐桌 1800→1500（贴皮替岩板）、餐椅 300→350/把、茶几 600→500，家具池净增约 +1.1k
- **关联文件**：`config/materials.yaml`（sofa_3seat_01/dining_table_01/dining_chair_01/coffee_table_01 重刷）、`docs/dressing-map.md`（重生成）、`assets/SOURCES.md`（BlenderKit 三件：Burrard 沙发/藤编餐椅/Noguchi 茶几）、`scripts/blender/dress_scene.py`
- **决策人**：业主

### DEC-2026-08-21-040 地板改案：推翻全屋人字拼，定案 600×1200 木纹砖步步高错缝通铺

- **日期**：2026-08-21
- **决策事项**：推翻 DEC-2026-08-20-024（全屋人字拼）；重定全屋地面铺法与选材口径
- **推翻原因**（业主）：人字拼成本爆炸（材料+工费上浮 20–50%+损耗 1.15+美缝量翻倍，DEC-024 自估 +6~10k），且效果未必最优——不值得为铺法差异付出该溢价
- **选定方案**：**全屋 600×1200 浅暖橡木木纹砖、步步高错缝通铺、近色环氧彩砂美缝（柔光/天鹅绒釉）**
  - 客餐厅+入户花园+走廊（floor topic，84.6㎡ 算量口径）：`floor_pbr_tile_612`（DEC-024 内置降级预案转正）
  - 四卧室（bedroom_floor topic，52.7㎡）：`bedroom_tile_612`（与客餐厅同砖通铺；备选仍保留 bedroom_wood_01 木地板，回南天需除湿，不作为默认）
  - 湿区（主卫/客卫/厨房/阳台，27.1㎡）：维持随 floor topic 同款通铺（既有口径）；客卫小花砖点缀仍为待决策 #8 池内可选项，不动底座
  - 色调纪律不变：浅暖橡木（tint #c49a6c）——DEC-025/027"浅地板+深中古家具+暖白墙"撞色结构不受影响
- **决策依据**：
  - 成本：错缝工费/损耗与直铺同级（loss 1.08），地面材料估算 ≈15.4k（客餐厅等 9.5k+卧室 5.9k），与人字拼落地价（21~25k）相比省 6~10k
  - 效果：612 长条比例接近木地板、错缝消除 800 方格感；DEC-024 三维对比中 612 仅次于人字拼，且 2026-08-12 A/B 走查直铺系夜景反馈"很舒服"
  - 风险：回南天砖基优于木地板；柔光釉拒绝深模具釉（沿用 DEC-024 门店四问纪律：版面数≥6/釉面/工费损耗/除蜡）
- **预算影响**：地面材料按暂估 75/片（0.72㎡/片，104 元/㎡）入账，门店报价后终核；泥瓦工费静态口径不变（人字拼上浮风险消除）；净省 6~10k 回补 190k ceiling 余量
- **遗留**：人字拼（floor_tile_herringbone_01 / bedroom_herringbone_01）降回候选，门店样板"能让人哇出来"才复活，否则正式放弃（沿用原纪律）；wet_floor 独立 topic（湿区防滑小砖）如需再立项
- **关联文件**：`data/current-scheme.json`（floor=floor_pbr_tile_612 / bedroom_floor=bedroom_tile_612）、`config/materials.yaml`（floor_pbr_tile_612 补真实计价口径 + 新增 bedroom_tile_612）、`app/src/render/TextureManager.ts`（pbr_texture 缓存键修复）
- **决策人**：业主

### DEC-2026-08-21-041 地砖系统抽象重构：单一 floor topic + 分房状态（roomOverrides 全链路贯通）

- **日期**：2026-08-21
- **决策事项**：重构地面/墙面选材系统——废除"全局一刀切 + 房间硬编码"，改为"房间多边形=状态单元"的分房选材架构；顺带修复墙漆链路两个既有缺陷
- **背景**（业主原话要点）："客厅区域可以考虑人字拼；卧室/卫生间/入户花园不用人字拼（开发商搞定了）"；"按照 vertices 架构，框出来的多边形标记房间号，就可以对它做状态更新"；对 keep_existing 特殊状态方案的否决："不用单独搞个状态，正常允许自定义，只是在决策日志跟预算表里可以 skip 它"
- **选定方案**：
  - **单一 floor topic 管全屋地面**：撤销 bedroom_floor topic（删 BedroomFloorTopic/BEDROOM_ROOM_IDS 硬编码、删 bedroom_tile_01/bedroom_tile_612/bedroom_herringbone_01 三条镜像材料，bedroom_wood_01 归入 floor）；`selections.floor = { default, roomOverrides }` 为唯一地面状态源，任何房间可 override 为调色板任意材料

  - **入户花园"开发商已铺"的表达方式**：不造特殊材质状态——渲染层照常可自定义；仅移出预算 applyRooms（不计费）+ 本条决策记录。显式 override 仍可随时为其计费（"显式覆盖始终尊重"既有语义）
  - **墙面系统同步升级**：PaintTopic/WallTopic 分房覆盖；天花 mesh 跟随所在房间墙漆（消除"点天花选漆却只改墙"的旧误导）
  - **既有 bug 顺带修复**：①designData 误用 `byTopicId('latex_paint')` 导致墙漆选项列表恒为空（材料 topic_id 实为 "paint"），墙漆方案此前从未真正应用；②buildFromCatalog 未重置 ceilingMeshes（重建泄漏）
- **初始状态**：floor.default=floor_pbr_tile_612，roomOverrides={}。客厅人字拼**不预设**——InfoPanel 点客厅地板→"仅当前房间"即可启用评估（MCP set_selection 带 roomId 同样可用）
- **预算影响**：地面算量范围=全屋除入户花园/电梯井（约 124.4㎡）；612 暂估口径 ≈14.0k；入户花园若日后显式 override 将重新计费
- **关联文件**：`shared/types.ts`（Topic.apply 第三参/floor_region.follow）、`app/src/topics/{FloorTopic,PaintTopic,WallTopic,TopicRegistry}.ts`、`app/src/render/{HouseScene,TextureManager}.ts`、`app/src/App.ts`、`app/src/data/designData.ts`、`config/materials.yaml`、`config/design-rules.yaml`（lineItems/objectMapping 不变）、`config/layout/overlay.yaml`、`server/overlay-merge.ts`、`config/procurement.yaml`、`data/current-scheme.json`

### DEC-2026-08-21-042 地砖分区定案：全屋浅橡木错缝通铺 + 湿区分化（防滑小砖/客卫小花砖）

- **决策事项**：地砖分区设计方案落地（室内设计口径，基于 DEC-041 分房选材架构）
- **设计主题**：「浅橡木为底，中古家具为主角」——底色安静温暖哑光，亮点交给家具与光；钱花在最大视觉面（客餐厅），但不靠拼花堆造型，靠大规格+近色缝+柔光釉铺出"整"
- **选定方案**：
