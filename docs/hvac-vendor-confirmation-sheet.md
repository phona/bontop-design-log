- 东侧 → 保留我方现坐标 (5.60, 4.00, h=2.50)，**只把墙段声明改成东墙 `w_gbath_west_open_vanity` + `wall_side: west`**，配置改两行、其他全不动
- 西/北侧 → 须改用「南墙门洞上方 (x≈5.0, z=4.30, h=2.50)」，并同步改电缆路径末段、确认 0.30m 深边吊能容插座盒
- 我方已核：东墙那段 0.75m 是机组旁唯一可安装检修面（西被通顶衣柜占死、南是门洞）；插座距门合页 1.09m > 门叶片 0.9m，且门高 2.1m < 插座 2.50m，**门打不到**

**B2 ｜28T2 /P-SS 实际外廓（长×宽×高）与接线盒位置图？**
- ⚠️ **明确不接受**：用 /PX-TS 参数表的 900mm 机身长度充数（#39 ① 原文禁止），也不接受拿三代 LHⅢ 参数图代替合同四代 LHIV 的证明
- 要的是**合同机型 /P-SS** 的外廓图

**B3 ｜2.50m 高位插座是否接受？**（替代方案 0.30m 低位藏机后，但机组在吊顶内、低位取电需长距离下引）

**B4 ｜共墙湿区签认**：儿童房东墙与客卫开放洗漱区共墙，插座在儿童房侧、高 2.50m——按 GB 55038 湿区划分应在区外，需电气侧签字
