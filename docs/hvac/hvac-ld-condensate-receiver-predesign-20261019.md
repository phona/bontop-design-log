## 2. 结构性判断（现在就能下的结论，含审查修正）

1. **管径/流量不是已知约束，但未排除。** 9 L/h 筛查估算说明常规口径下 φ25 不构成已知瓶颈；但间歇泵瞬时排量、三台并发（14.1kW）、共用受水器与下游支路容量均无厂家数据（#39），不能反推「管径已排除」或「可直接跳 DN40/DN50 共管」。
2. **湿区不是成本问题，是工序问题。** 客卫内卫的风险表述改为工序口径：吊顶空腔仅 150mm 且已被浴霸排风管 φ100+风机占位（duct_gbath_exhaust (6.10,2.45)）；沉箱内已有淋浴地漏、干区地漏、马桶 de110 排污、台盆墙排 DN50 穿墙；LEB（#43）无坐标但须防水前预埋。**注意**：审查指出本项目尚未施工，不得以「返工代价高」提前淘汰客卫方向——客卫保留为备选，比较口径 = 新增穿透、维护可达性、失效损失。
3. **厨房线的真实障碍是标高与构造，不是距离。** 新增几何约束：厨房北墙是实体上飘窗 `kitchen_north_bay`（包络约 x[7.20,10.80]×z[0,1.10]×y[2.12,2.83]），排水立管候选 (10.50,0.30) 就在其投影内——高位管走到立管上方会穿窗台体。「尽早下引」必须具体化为：在飘窗以南何处降点、降后如何绕柜体/灶烟区、以什么标高进入受水器；`sill_crossings` 声明不授予开孔许可。
4. **独立管不增加可用落差。** 共管 J1 段约 4mm 余量来自长度/坡度/标高窗；同路径改独立管不会自动增加落差。能改变结论的是：降点位置、降后低位通道、泵提升段、局部建筑调整。我 v1「共管 4mm 问题不存在」的表述过头，已删。
5. **#39（P-SS 泵出口标高/扬程/止回/高水位保护/是否需存水弯）是全部剖面方案的前置。** 在厂家资料到手前，任何「重力成立/不成立」只能是条件性结论。
6. **现配置两条路线坡度不达标（审查硬算实证）**：儿童房 condensate-child 水平 1.632m/落差 10mm（分段 0.909%+0%×3）；主卧 condensate-master 水平 5.1m/落差 49mm（第 4 段 0.706%、第 7 段 0% 平坡 0.2m）。主卧线必须先重画逐段标高再比选。

## 4. 推荐设计基线（供业主裁定，非冻结）

1. **受纳系统**：首选厨房排水立管；备选客卫干区（维持 R25 落点）；阳台殿后。任选都必须落到「可识别的实物名称+接口位置」（审计稿 §3 口径），推断锚点不是接口。
2. **拓扑**：各台独立 φ25/φ32 支管，不共管。收益限于：支管级故障隔离、清通独立。**不隔离**：共用受水器、下游支路、立管堵塞。共管与否（含 DN40/DN50 主管+可拆清扫口）待厂家按准确型号书面确认（P6）。
3. **厨房线走向**：北缘边吊 z=4.6 轴线→餐厅北服务带→门厅吊顶→过餐厨推拉门上口（套管；**两台独立管 = 两个穿越位置，不是一个套管**）→厨房铝扣板吊顶→**在 kitchen_north_bay 飘窗以南定降点**→降后绕柜体/灶烟区→受水器。降点与实际烟管（duct_kitchen_exhaust (10.60,1.50)）、灶/烟机 (10.50,1.50)、水槽柜（排水/RO/抽屉）同剖面确定，不交给现场自由选择。
4. **接入构造（P1，前提性）**：**间接排水受水器**——排水管口→空气间隙（按 GB 50015-2019 表 4.4.14 按管径查取，150mm 可作项目加严值）→受水器溢流边缘→水封→获准支路。水封/止回是辅助。禁止直插立管、禁止共用其他器具存水弯、禁止接地漏/马桶排污/洗衣机专用排水/二次排水。
5. **坡度（P2）**：支管 ≥1%、干管宜 ≥5‰（不应 <3‰）、全程无上弯无凸起；竖直段不计坡长；转弯用适用弯头（不拿三通泛称）；逐段标注坡度并实算，不满足就重画，不拿声明值当实际值。
6. **保温（P4）**：按防结露核算定厚（6mm assumed 与暂估 10mm 都待核），重算外包络（含穿墙/支架冷桥）对门头、梁带、厨房 150mm 空腔、Y 节点的净空影响。
7. **泵与失效（详见 §5）**：厂家提供接水盘/出水口剖面、待机余水、止回做法、浮子高水位保护；远端受纳系统独立设防（受水器堵塞时机内浮子无感）。

## 5. "X 不工作时"清单（按项目铁律 1，随 DEC 一并落 pending）

- **待机/停机**：分段标出哪段保水（提升段、止回阀上游、接点水封）、哪段应自空（重力段），不用「全程无上弯」一句带过；泵后回落水去向按厂家剖面定。
- **停机倒流**：止回失效首先是提升段存水回落；止回阀不承担生活排水隔气功能；存在正确空气隔断时，不把「污水倒灌接水盘」写成正常拓扑的必然后果。
- **泵/浮子故障**：接水盘溢水发生在内机处（客厅边吊），与排水路线无关——但这只是故障谱系的一支。
- **受水器堵塞而泵正常**：机内浮子**完全无感**，水从受水器/隐蔽段/柜内失出——远端受纳系统必须独立设防（高水位报警、溢流导流、可视检查口），这是本轮审查最重要的新增失效模式。
- **接头脱开/清扫口漏水**：失水点在柜内或隐蔽管段，不是「一定漏在内机」。
- **维护**：受水器水封有非制冷季干涸、清扫后未补水、排水压力扰动三种失效；须定检查入口、补水办法、负责人、触发条件（官方运行指引要求检查凝结水 U 形管水封、缺水补水——不据此编造固定周期）；清接水盘/滤网走回检一体格栅；清管路径=可拆铝扣板/柜内清扫口，不得拆顶；维护责任写入合同并落到人。

## 7. 系统级验收判据（check_hvac_drain 只覆盖内机注水，必须扩展）

| 场景 | 必须记录的通过判据 |
|---|---|
| 六台分别运行、同受纳系统并发泵排 | 全路径无渗漏；受水器无溅水/满溢；排出口不被淹没；空气间隙保持 |
| 单机停机其余运行、整组断电 | 无跨机回流；回落水不造成接水盘溢出；排空与残水量符合厂家要求 |
| 按厂家方法模拟泵故障/高水位 | 保护在外溢前动作；记录停什么、是否报警、恢复条件 |
| 单支管堵塞、受水器出口堵塞分别模拟 | 水不排入柜板/电气/隐蔽结构；验证安全导流或停机措施，不假定机内浮子能发现远端满溢 |
| 受水器接入支路的正常其他用水工况 | 无倒灌、无水封异常波动、不破坏空气间隙 |
| 实际维护操作 | 能开清扫口、拆洗受水器与水封、清盘、拆泵；不以「有检修口」代替实操 |
| 冷运行与最终柜体安装后 | 查接头/支架/穿墙结露；复验坡度、检修可达性、托盘与报警 |

空调、水电、柜体施工方共同签认系统结果；穿防水处做防水工序交接；覆盖封板前与最终包覆后两个状态。
