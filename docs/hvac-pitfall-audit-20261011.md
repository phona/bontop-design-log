# 中央空调安装前核对稿：现状、排水基线与现场交底

**版本**：v4.3 排水路线与历史依据核对稿（2026-10-11）  
**状态**：方案复核稿；须在交房量房、厂家资料和现场排水点核实后，才能转成施工深化图。  
**目的**：安装人员上门前，逐台核对合同设备、机位、风口、排水受纳点、供电和检修条件。首要目标是降低漏水、返味、拆顶和日后维护风险；无泵只是当重力路线短、可靠、可检修时采用的手段。

## 2. 建议设计基线

**合同基线与设计初稿分开：**合同记录的是 20kW 外机、六台 `/P-SS` 带泵内机及 25.3kW 逐房配置，不因本稿自动变更。设计初稿保留一拖六和 20kW 外机作为平台核验基线；容量另以客厅 71／餐厅 28／主卧 56／书房 28／儿童房 22／客房 22（合计 22.7kW、名义连接率 1.135）向门店索取完整比选报价和逐房负荷计算，未经计算与业主确认不锁此表。排水逐台比较“原配泵＋可检修的短路线”和“兼容无泵机＋连续重力路线”的完整代价。若去泵迫使管道长距离暗敷、跨多个房间或失去清堵口，可保留厂家原配泵；但泵同样必须接到真实受纳点，并通过停机倒流及高水位保护试验。不得默认带泵机可停泵当无泵机使用。

重力排水需要同时满足：从接水盘出口到真实受纳点连续下降、途中梁/吊顶净空允许、管径和存水/防臭做法经厂家及水电确认、末端可检修。**把水管接到吊顶中的一个候选坐标或竖管附近，不等于找到了排水受纳点。** 每台方案必须画到实际立管支管、经确认的排水器具支路或获准的其他受纳点，并标出隔气/防臭做法。

**泵风险的正确口径**：带泵系统可能有接水盘余水、浮子/泵堵塞或停机倒流风险，但无泵系统也可能因管线反坡、低点、堵塞或防臭水封失效而积水返味。美的其他带泵内机的[排水试验资料](https://assets.midea.com/ImageStore/107852/instructions/e996ec11a8a5b96993af40c6ba783d3e.pdf)要求停机后检查倒流与溢水；[Trane 排水维护说明](https://www.trane.com/residential/en/resources/troubleshooting/air-conditioners/ac-drain-line-clogged/)说明积水和污物可能造成堵塞、异味及溢水。这些是风险机制旁证，**不是本合同 MJV-T2/P-SS 的余水量、故障率或维护周期证明**。在精确型号手册到手前，不得以“小红书说带泵一定存脏水”或“无泵一定省心”作为逐台换机依据。

本文的排水坐标均按平面 `x/z`（米）记录；`y` 单独表示高度（米）。例如 `indoor_master` 的平面轴心 `(3.70, 5.10)` 不表示高度 5.10m。图纸坐标与标高均属方案/模型口径，不能替代现场复尺。

### 3D 初稿怎么看

在客户端「图层 → MEP 协调 → 冷凝水」检视六条现存路线：`condensate-living`、`condensate-dining`、`condensate-master`、`condensate-child`、`condensate-parent`（现书房）、`condensate-study`（现客房）。青色虚线是模型中的候选路径；红色终点标记表示路线仅止于冷凝水候选坐标，**尚未接上真实排水点**。客餐厅共用候选终点，所以六条线只有五个不同的末端。打开「转折点/标高」可逐段对照坡向与梁带；模型标高是待现场核验的方案值，不能用截图代替厂家剖面或现场量房。本稿没有为生活阳台替代线、主卧低位穿墙段或书房/客房新接点凭空画管；这些正是下一轮需要空调与水电共同补到模型里的工作。

[查看六台排水走向平面示意](design-iterations/hvac-preinstall-20261011/evidence/drain-routing-plan.png)：客厅蓝线、餐厅浅蓝线、东南客房红线拟汇入深蓝色**厨房共用主管**；灰色长线是客房到客卫备选，灰色短线与红叉表示**当前 3D 旧路线在客房西侧即终止**。示意图不含可施工标高，墙/门/梁轮廓也作了简化；要判断能否隐蔽、保坡和接入，仍以本文件逐台剖面要求为准。

**当前主选线的冷凝水穿越预留数**：图中 1–3 是 **3 处模型墙段穿越**——主卧南隔墙、儿童房到客卫西隔墙、书房北墙；4 是 **1 处客房门头穿越**；5 是 **1 处餐厨推拉门上口穿越位置**。所以平面有 **5 处穿越位置**。若三台厨房支管各自穿过餐厨门上口，是 **7 次管线穿越/潜在套管**；若按图在可检修的 J1/J2 先汇流，只让一根合格主管穿上口，则是 **5 次管线穿越**。共管须先核管径、坡度、泵停机互串、汇流处检修及厨房受水点，不能为了少打两个孔就暗接三通。1–3 的墙材、结构和能否开孔均待实测/审批，尤其儿童房侧墙目前只有模型墙线，不能由图上有墙推定为可钻实体墙。受水器接入污水支管可能还需另开接口，柜体、吊顶检修口也另算。现在所有孔位都只是规划，未有一个已施工或获准开孔。

这些数字**只针对本图六条冷凝水主选线**。现行 MEP 数据另外记录了冷媒、电源和旧冷凝水共 **12 条路线声明穿墙**，涉及 **7 个墙段、8 组候选穿点**；这不是 8 个已开的孔，也不能与本图管次直接相加。其中主卧进线需经过标为推断剪力墙的 `w_strip_east`，必须先确认墙体与允许穿孔方式。本图候选线在当前模型中没有穿已标幕墙，但现场墙材仍待确认。

**三台到厨房的共管比选**：平面可在 `J1=(10.80,4.60)` 汇入东南客房与客厅两支管，在餐厅北服务带内 `J2=(10.50,2.60)` 再汇入餐厅支管，随后一根主管从餐厨推拉门上口进入厨房，落到**尚未确认的厨房冷凝水受水点**。按这些坐标算，三条独立长管到厨房约 **23.15m**，在 J1/J2 合流后约 **16.25m**，两处汇流均须有可开启的检查/清通位置。长度减少和上口少穿两根管是共管的收益；共同主管堵塞将同时影响三台，是必须通过可清通和排水保护控制的代价。

**共管最紧的剖面**是 J1 到厨房，平面约 4.60m；按初稿 1% 坡度至少需落 46mm，而模型 A 区承载上限 2.75m 到厨房 B 区下限 2.70m 仅 50mm，理论余量约 **4mm**，还没算管径、保温、吊码和施工偏差。因此现有吊顶标高下不能把共管当成已可藏入的做法；厂家须重画实机泵出口和主管管底标高，并与吊顶/门轨同图核空间，必要时调整局部吊顶或改独立路线。共管是否适用于本合同的三台 `/P-SS`，还须厂家按准确型号书面确认泵出口、止回/互串、并发流量、主管管径及试验方法。美的[同类高静压 VRF 风管机手册](https://mbt.midea.com/content/dam/midea-aem/mbt/hvac-goods/midea-products-category/vrfs/vrf-idu/high-static-pressure-duct-mdv-d400-d560t1-n1/pdf1.pdf)允许多台带泵机汇入排水主管，但该手册**不适用于本合同 MJV-T2/P-SS 的具体参数**。

**剖面门槛**：同类美的风管机[官方安装手册](https://dsdcp.smartmidea.net/mcsp/prod/20250115/bcee30db0e444d12b335a7c9a4ba569b.pdf)要求其适用机型的水平排水连续向排水侧下坡、避免凸起存水，室内管与接口保温，并检查泵后倒流；该手册适用的是 KFR-T2W，不是本合同 MJV-T2/P-SS。以上候选仍须用**本合同准确型号**的安装图核排水口、允许扬程、管径和检修空间，不能移用手册的泵扬程数值。

### 排水图和算量的统一口径

1. 每台先标接水盘出口，再沿管心逐个标注平面折点 `(x,z)`、各点管底标高 `y`、坡向、管径、长度和穿越对象。路线长度按各正交段实长相加；斜向/直线距离仅可作下限参考。
2. 标高核算使用同一基准，记录接水盘出水口、每个梁下/吊顶段、下引起点、受纳点入口的实测标高。坡度按每段水平长度与高差核算；竖直段不计作水平坡长，也不能替代末端水平接管。
3. 把受纳点写成可识别的实物名称与接口位置，并拍照标记。立管锚点、地漏模型点、吊顶内候选坐标不自动等于可接接口。
4. 防臭/空气隔断、泵后接法、汇流、存水弯、清扫/检修方式由空调厂家和水电负责人书面确认；禁止直插立管或把冷凝水接入洗衣机专用排水。

### 一期/二期接口

一期要完成设备安装所需的排水管、套管、保温、防结露、坡度、接入、防臭、检修和测试，并为后续包覆预留接口。二期家具/柜体可以收纳或遮蔽部分管线，但不能成为一期排水成立的前提，也不能封死接头和检修点。项目阶段排除信息只用于识别延期家具件，不得据此把空调机电排水、套管或测试推到二期。主卧条带家具、底柜和饰面最终边界须与一期管线位置同图复核；现场未定时保持可见、可检修的过渡态。

- [ ] 主卧专项同时比较主卫独立受水点、条带洗手柜可检修受水器与干区地漏接法。旧 MEP 末点、方案 A 条带下引点到干区地漏的模型正交长度下限分别是 1.35m、2.45m；实际管长、穿墙、盆排水封和柜内检修逐段复核。不得只写“竖管下到地面”或“落差足够”。
- [ ] 客厅厨房方向 5.25m、餐厅厨房方向 7.75m、东南客房厨房方向至少 10.15m 分别出剖面；J1/J2 共管须说明三台总流量、泵停机互串、汇流与分支清堵，附三台分别/同时注水试验。餐厅客卫和生活阳台备选按正交折线复核。
- [ ] 书房北向客卫约 2.50m 平面候选明确 `w_st_north` 穿点与净空；东南客房到客卫洗漱柜方向约 10.50m 是厨房共管不成立时的备选，也须出完整剖面。书房、客房和儿童房均须指定真实受纳点，不留“候选点待接”的口头结论。
- [ ] 先向门店取得各房间原配带泵与兼容无泵 SKU 的准确型号、排水口位置、低位出口标高、风量、噪声、机身外廓和同口径变更价；书面确认定金及锁货状态。仅在厂家明确允许时才讨论带泵机旁通，不能自行停泵。
- [ ] 提交分项报价和超预算处理办法；注明税、复合风管、风口加长、附加管线、开孔、封堵、支架、冷媒抽真空/保压、排水注水测试、调试及保修范围。
- [ ] 封板前逐台做排水注水试验并留影像，核对无渗漏、倒坡、滞水、返味和回风短路；保留坡度/高程记录、设备铭牌、调试记录和双方签字。

## 6. 当前结论

**今日可定：不按“六台全部带泵”直接锁货，也不以“六台全部无泵”为目标。** 保留合同为商务基线，按上述 22.7kW 容量比选表和逐台泵/重力排水方案要求门店出图出价。排水按三个厨卫污水方向组织：客厅、餐厅、东南客房先研究厨房同一受水点及 J1/J2 可检修共管；儿童房和书房先查客卫；主卧比较主卫独立受水与条带洗手柜。共管不成立时保留三台独立支管或餐厅/客房改客卫的备选，不能为了省管和省孔取消必要的清堵/防回流措施。生活阳台作为客餐厅二级备选，入户花园已由业主排除。任何一台都不能仅凭“有泵”或“有落差”宣布排水闭环；厂家资料和量房实测决定最终 SKU 与施工图，反转时记录理由和全安装成本。
