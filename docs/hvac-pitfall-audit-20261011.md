> 以下为 `docs/decisions/05-hvac.md` DEC-2026-10-03-R6 原文摘录：

1. **"儿童房/书房维持 22 级（北向玻璃无直射 / 面积小），不为'留裕度'升档"**
   → R1 把三间全升到 28 级。
2. **"22T2 低风噪音 17dB(A) 优于 28T2 的 19dB(A)"**
   → R1 让三间卧室全部放弃 17dB，改用 19dB。
3. **"22/28/36 机身同为 700×450×200mm，故儿童房/书房选 22 级无安装差异"**
   → 换小容量**不影响任何已定吊顶几何**，改动成本为零。
4. **"不为 22.4kW 多付约 3,500，转投主卧电动西窗帘（砍 0.6–0.9kW 太阳得热，每日兑现）"**

**审计判断：R6 的配置在容量精度、卧室噪音、连接率、成本四个维度全部优于 R1，且改动不触及任何已冻结的吊顶几何。R1 相对 R6 是净退化，且退化原因无记录。**

这是项目自己的工程结论（2026-10-03）。本文 §3.2 提出的"衣柜竖直下引"是 2026-10-06（DEC-2026-10-06-R5）之后才形成的路线，**未经项目验证**。

### 3.4 排水施工四条红线

1. **接入点必须做水封/防臭**，不能直插立管或地漏。直插 = 地沟味从吊顶倒灌进回风口。
2. **不和洗衣机共管**——你家给排水既有原则（防共路反水）。冷凝水单独开三通，且阳台立管 DN110 上已有洗衣机一个三通，需施工方核是否可开第三个。
3. **柜体内下引段必须预留套管 + 带坡度 + 发泡胶封堵 + 可拆卸盖板**（`#55` 已显形：主卧穿 4 段墙、与 6 件家具重叠）。
4. **坡度记录逐台留档**：出水口标高 / 完成面标高 / 接入点标高 / 水平长 / 实测坡度。

## 4. 主卧专项（v3.0 补入玻璃与一期/二期边界）

### 4.1 玻璃面积（推翻 v2.0 的容量建议）

| 面 | 数据 | 来源 |
|---|---|---|
| 南墙 | `curtain_box_master_south` 覆盖 **x[0, 4.20] 整开间**；另记窗 2.40×1.50 + 飘窗 1.80×1.50 | ceiling.yaml / house.yaml |
| 西墙 | `curtain_box_master_west` 覆盖 **z[5.55, 8.80] = 3.25m** 玻璃 | ceiling.yaml |
| 西南 | "北移避开**西南圆弧玻璃幕**" | house.yaml furnishings |
| 玻璃根 | 业主 2026-10-07 断言「**都是落地窗**」（C17），齐地幕墙处理；`#54` 主卫两段待核 | pending-site-data #20/#54 |

**估算玻璃面积 ≈ 4.20×2.4 + 3.25×2.4 ≈ 17.9㎡，与寝区地板面积 17.85㎡ 相当。**

**负荷粗核**：西向落地玻璃 7.8㎡ × 450–550 W/㎡ ≈ 3.5–4.3 kW；南向 10.1㎡ × 200–300 W/㎡ ≈ 2.0–3.0 kW；围护+人员+设备 ≈ 1.3 kW → **合计 6.8–8.6 kW**，而 `hvac.yaml` 记的设计负荷仅 4.5 kW（251 W/㎡，业主/经销商估算口径）。

**但 R6 的解法不是加容量，是电动西窗帘**："转投主卧电动西窗帘（砍 0.6–0.9kW 太阳得热，每日兑现）"。电动窗帘电源已在 `smart_home` 预留。**这条比加大内机更有效且已决策，需确认窗帘是否落实。**

### 4.2 主卧真正的短板：0.6m 窄送风口

`supply_master`：长 **0.6m**、y=2.62、南向侧送。5.6kW 机风量约 900–1100 m³/h，按 0.6m × ~0.12m 开口算：

**风速 ≈ 3.5–4.2 m/s**，线性风口舒适上限一般 2.5–3 m/s → **偏快，会吵、有直吹感、风量上不去。**

**建议：送风口从 0.6m 加宽到 1.0–1.2m（或分两段）。成本只是风口加长费，收益直接，且与单双出风之争无关。高负荷房间更该先修这个。**

### 4.3 一期/二期边界（影响施工顺序）

`schedule/phase-scope.yaml`：**主卧 950 通顶衣柜（`master_north_wall_wardrobe_950`）与全部冷凝水管构件（`condensate_pipe_ac_outlet` / `mb_vanity_pvc_*`）都在一期 `exclude_types`，归二期 `P2-100`。**

`P2-100` 原文：**"一期过渡态：条带为 1.05m 洗手柜可用、无底柜收纳、冷凝水管裸露于主卧墙面，属已知可接受过渡。"**

**含义：空调一期装，收纳冷凝水管的柜体二期做。一期内主卧冷凝水管是明装裸露态。**
→ 水电/空调交底时必须明确：一期管路的最终走向要为二期柜组留位，避免二期柜体做好后管子被包死无法检修。

### 4.4 邻居风险（非 HVAC，但卡同一道工序）

`#56`：两卫均无可用外墙（主卫西/北=玻璃幕墙禁穿孔，客卫四面内墙），`acceptance.yaml` 的"排风出外墙 φ100"口径对两卫**均不可施工**。若开发商未预留卫浴公共排气道，**两卫无合规排风路径，为设计级硬伤，且影响"带+漆"成立性**。

**此项未闭环，两卫饰面与吊顶不得冻结**——与 HVAC 共用同一道封板门禁。

单开一间房的外机启停噪音（降连接率有利）｜外机位散热（1.39㎡ 放 20kW）｜外机噪音传入｜深度清洗 6×200–400 元/次｜生物膜堵塞｜西晒｜冷凝水管走厨房地面被家具妨碍。

### 5.4 只能硬踩

**外机只有 1 台，坏=全屋没空调（无技术缓解，只能买延保）**｜一台内机坏=一间房没空调且可能拆顶｜化霜吹冷风｜制热到不了地暖感｜滤网要搭梯子洗｜十年后换机重做风口。
