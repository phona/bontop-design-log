# 设计师 Brief

## 项目基本信息

- **楼盘**：和萃
- **房号**：701
- **套内面积**：94.76㎡
- **预测建筑面积**：119.38㎡
- **层高**：结构层高 3.0m，室内净高 2.8m
- **户型**：四房两厅两卫
- **楼层**：7楼 / 板楼 / 西户
- **城市**：南宁
- **核心需求**：入户花园作为玄关过渡区；保留四房两厅两卫基本功能；开放式厨房；电视墙（西墙）；当前空间功能为主卧、书房、客房和西北次卧；预算务实

## 设计原则

1. 设计几何以 `config/layout/model-geometry.yaml` 为唯一权威源，采用房间中心坐标和墙体角点坐标；`config/house.yaml` 的房间尺寸与面积只作镜像字段。交房复尺前，现场尺寸、梁底、门窗和设备平台仍标记为待核，不能用估算替代量房记录。
2. 不得改动承重墙、梁柱、外立面。
3. 外立面为开发商玻璃幕墙，不得拆改；门窗口位置需与幕墙分格协调。
4. 入户花园（开敞外廊）含消防通道，不能完全封闭，需保持消防动线。
5. 开放式厨房必须配大功率侧吸油烟机（≥22m³/min），确保油烟不外溢。
6. 全屋玻璃幕墙（三层 Low-E 中空玻璃，开发商已装），隔热已满足；窗帘主功能为遮光+防眩光+隐私，主卧/客厅/客房/书房预留电动窗帘电源。
7. 一期预算以 `schedule/phase-1/control.yaml` 为准：执行上限 ¥210,000，已分配 ¥210,000，未分配 ¥0；基础硬装 ¥126,000、中央空调 ¥36,000、一期家具 ¥19,000、必需家电 ¥16,000、设计与开工准备 ¥8,000、一期窗帘 ¥5,000。`config/budget/base.json` 的旧四池预算只作历史参考。
8. 主材品牌型号需经业主确认。
