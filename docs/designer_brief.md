# 设计师 Brief

## 项目基本信息

- **楼盘**：和萃
- **房号**：701
- **套内面积**：94.76㎡
- **预测建筑面积**：119.38㎡
- **层高**：3.0m
- **户型**：四房两厅两卫
- **楼层**：7楼 / 板楼 / 西户
- **城市**：南宁
- **核心需求**：入户花园作为玄关过渡区；保留四房两厅两卫基本功能；开放式厨房；电视墙；书房预留未来改卧室可能；预算务实

## 设计原则

1. 所有尺寸以 `config/house.yaml` 中净尺寸为准（目前为按面积估算，量房后修正）。
2. 不得改动承重墙、梁柱、外立面。
3. 外立面为开发商玻璃幕墙，不得拆改；门窗口位置需与幕墙分格协调。
4. 入户花园（开敞外廊）含消防通道，不能完全封闭，需保持消防动线。
5. 开放式厨房必须配大功率侧吸油烟机（≥22m³/min），确保油烟不外溢。
6. 全屋玻璃幕墙，窗帘为遮阳隔热与隐私刚需，主卧/客厅/书房预留电动窗帘电源。
7. 预算目标 11 万，务实档，保证基础质量，不做豪华造型。
8. 主材品牌型号需经业主确认。
