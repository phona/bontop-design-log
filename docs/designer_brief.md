# 设计师 Brief

## 项目基本信息

- **楼盘**：和萃
- **房号**：701
- **套内面积**：94.76㎡
- **预测建筑面积**：119.38㎡
- **层高**：3.0m
- **户型**：四房两厅两卫
- **楼层**：7楼 / 板楼 / 西户
- **城市**：南宁
- **核心需求**：入户花园作为玄关过渡区；保留四房两厅两卫基本功能；预算可控

## 设计原则

1. 所有尺寸以 `config/house.yaml` 中净尺寸为准（目前为按面积估算，量房后修正）。
2. 不得改动承重墙、梁柱、外立面。
3. 外立面为开发商玻璃幕墙，不得拆改；门窗口位置需与幕墙分格协调。
4. 入户花园（开敞外廊）含消防通道，不能完全封闭，需保持消防动线。
5. 预算受控，主材品牌型号需经业主确认。
