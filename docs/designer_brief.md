# 设计师 Brief

## 项目基本信息

- **楼盘**：和萃
- **套内面积**：120㎡
- **户型**：四房两厅两卫
- **楼层**：7楼 / 板楼 / 西户
- **城市**：南宁
- **核心需求**：待从概念方案中选定

## 设计原则

1. 所有尺寸以 `config/house.yaml` 中净尺寸为准。
2. 不得改动承重墙、梁柱、外立面。
3. 入户花园改造方案需符合物业规定。
4. 预算受控，主材品牌型号需经业主确认。
