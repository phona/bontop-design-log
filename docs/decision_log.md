### DEC-2026-07-05-003 确定入户花园范围与用途

- **日期**：2026-07-05
- **决策事项**：入户花园的范围、面积和功能

### DEC-2026-07-05-005 80% 方案共创定稿

- **日期**：2026-07-05
- **决策事项**：确定空间功能、MEP 方案、吊顶形式、窗帘及预算档位
- **可选方案**：
  1. 东北次卧：书房 / 客房 / 儿童房
  2. 厨房：开放式 / 封闭式
  3. 客厅：电视 / 投影
  4. 主卧飘窗：保留 / 拆除
  5. 热水：燃气 / 电热
  6. 智能：预留 / 不预留
  7. 吊顶：局部 / 全屋 / 不吊顶
  8. 预算：10万 / 11万 / 12-13万
- **选定方案**：
  - 东北次卧 = 书房（预留改卧室可能）
  - 厨房 = 开放式，配大功率侧吸油烟机
  - 客厅 = 电视
  - 主卧飘窗 = 保留
  - 热水 = 燃气热水器
  - 智能 = B 级预留（智能开关零线 + 网关 + 电动窗帘电源 + 传感器位）

  - 窗帘 = 全屋刚需（纱帘 + 遮光帘）
  - 预算 = 11 万务实档
- **决策依据**：两人居住，不需要一步到位；玻璃幕墙导致窗帘和遮阳为刚需；仅一个设备平台限制空调方案
- **预算影响**：预算从 11 万 draft 定稿为 11 万务实档，新增窗帘、智能预留、油烟机科目
