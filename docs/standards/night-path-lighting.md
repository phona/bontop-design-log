# 起夜路径照明标准（Night-Path Lighting Standard）v1

> 定位：**可复用标准**，不绑定任何户型坐标。任何住宅只需填入“夜路径”点位即可落地。
> 来源：和萃 701 迭代 `parent-room-study-swap-20261005`（2026-10-05 业主立项：父母房/客房与主人区隔开后，起夜动线变长，要求"人接近即自动亮起地面灯"）。
> 状态：v1 待在本户实施中验证；验证回改后升 v2。

---

## 1. 适用范围

- 有老人、病人、幼儿、或夜间需要如厕的家庭；
- 卧室与卫生间不同层/不同翼、或距离超过约 3m 的户型；
- 一切"起夜是高频且必须可靠"的场景。

不适用：短动线（卧室门到卫生间 ≤2m 且无门槛）的户型——那类户型用床头小夜灯即可，不必做路径系统。

## 2. 术语

| 术语 | 定义 |
|---|---|
| 夜路径（night path） | 从床上（起夜起点）到卫生间（终点）再返回的连续通行轨迹，**含门、门槛、材质分界、转弯和停留位** |
| 段（segment） | 夜路径按空间性质切分的最小单元：房内段、出门段、过渡段、走廊段、卫生间段 |
| 停留位（dwell point） | 人会在黑暗中停住的位置：门口、洗手台前、马桶前、楼梯口 |
| 保底控制（fallback control） | 不依赖网络、网关、云、App 就能工作的控制方式 |

## 3. 设计输入（动手前必须查清的六项）

1. **起夜人是谁**：决定照度、感应灵敏度和安装高度（老人需更高更早触发）。
2. **路径全长与分段**：实地走一遍，标出门、门槛、推拉门、转弯、材质分界。
3. **既有灯位与回路**：哪些日常灯在路径旁可作兜底；强电箱有没有备用回路和空间。
4. **地面完成面与门槛高差**：决定能否装地脚灯（0.25–0.40m）与感应朝向。
5. **既有设备占位**：扫地机基站、窗帘盒、柜体踢脚、家具阻挡，一律避让。
6. **共用/分睡情况**：是否影响同房伴侣——影响床头段控制策略（触摸/按键优先于感应）。

## 4. 点位规则

1. **逐段覆盖，不留 >3m 暗区**：每段至少一个感应点；过渡段（最暗最宽，常跨厅）优先加密。
2. **门内外双侧布点**：门内一个（照亮出门动作），门外一个（照亮落地后的第一步）。夜路径上每一道门都是风险点。
3. **停留位必须用"存在感应"**：马桶前、洗手台前、楼梯口——人站着不动时 PIR 会超时熄灭。
4. **安装高度 0.25–0.40m**，光束朝行进方向的墙面或地面，**不得直射床面与眼睛高度**。
5. **朝向规则**：感应窗口朝人来方向，背向窗帘/通风口/热源（减少误触发）。
6. **每段可独立失效**：单灯故障不得让整段变黑——相邻段覆盖角 ≥30°，或路径旁有日常灯兜底。

## 5. 光学与电气规格

> 下表为 **v1 候选默认值**（工程经验值，非规范引用值）。实施中按选型与现场实测调整，验证结果回写后升 v2；调整必须记录依据，不得静默更改。

| 项 | 候选默认值 |
|---|---|
| 色温 | 3000K（与全屋统一色温；不得混用冷白） |
| 地面照度 | 起夜路径 5–15lx（看得见、不醒透）；卫生间内 10–20lx |
| 显色 | Ra≥80 |
| 防眩光 | 暗藏/遮光角/反光方式，1.5m 视高无直射眩光 |
| 安装高度 | 0.25–0.40m |
| 感应 | PIR（移动）+ 关键位存在感应；延时 30–60s；可选光照度感应（白天不亮） |
| 回路 | **独立照明回路**（如 `lighting_night_path`），C16A，从强电箱单独敷设；不与日常灯、插座、动力混回路 |
| 智能预留 | 灯位留零线、留传感器位、留网关可达；升级联动有路可走，但**不作为唯一控制手段** |

## 6. 控制分层（硬规则）

- **保底层（必须）**：路径各段独立 PIR 感应自控。断网、网关故障、App 卸载，都不影响起夜。
- **体验层（可选）**：床头触摸/按键 + 感应的调光小夜灯，低声起步、不影响同房伴侣；可接入智能系统做延时与场景。
- **禁止**：把起夜照明作为智能场景的唯一承载；禁止感应灯与日常主照明共用开关控制（否则"只亮夜灯"不可达）。

## 7. 失效模式与验收

验收清单（逐项打勾，缺一不可）：

1. 从床到卫生间全程走一遍，**没有任何一段出现全黑**（关日常灯测）。
2. 每个停留位站立 60s 不熄灭。
3. 拔掉网关/断 WiFi 后重走一遍，功能不变（保底层验证）。
4. 任选一盏灯断电，路径仍不全黑（独立性验证）。
5. 躺在床上，感应灯不直射面部（眩光验证）。
6. 白天强光下不误亮（若有光照度感应）。
7. 与扫地机/窗帘/柜体/家具无干涉（避让验证）。
8. 停电时主照明兜底可用（就近日常灯可手动开）。

## 8. 复用到新住宅的步骤

1. 画出夜路径 → 分段 → 标门/门槛/转弯/停留位；
2. 查既有灯位与强电箱 → 定 `lighting_night_path` 回路；
3. 按 §4 布点，按 §5 选型，按 §6 分层；
4. 按 §7 验收；
5. 把本例的"设计输入"和"点位表"回填到本标准的案例库，反哺下个户型。
