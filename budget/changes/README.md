# budget/changes / 变更记录

所有施工过程中的变更都必须以独立文件记录，禁止口头变更。

## 命名规范

`CHG-YYYY-MM-DD-NNN.json`

例如：`CHG-2026-0715-001.json`

## 变更流程

1. **触发**：工长提议 / 设计调整 / 现场条件 / 业主主动要求
2. **评估**：AI 或人工评估必要性、成本、工期影响
3. **决策**：业主确认批准或否决
4. **执行**：施工并保留凭证
5. **归档**：新建变更文件，更新 `budget/base.json`，Git commit

## 模板

见 `budget/changes/CHG-YYYY-MM-DD-001.json`（可创建副本使用）。
